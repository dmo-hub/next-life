## ค่าเริ่มต้นจากใบ 207

- ชุดการ์ดสนุกที่ไม่ใช่เหตุบ้านเมือง: `years: [2500, 2650]` + `weight: 1` · เจ้าของกลับคำจากผูกปีจริงเป็นออกทุกปีเมื่อ 2026-11-06 · ถ้าเรื่องใหม่ต้องการปีจริงให้ถามเจ้าของใหม่ ห้ามถือว่าใช้ข้อตัดสินนี้
- ยื่นค่า weight ต้องมีตัวเลขวัดของทั้งแบบกั้นปีและไม่กั้นปีในรอบเดียว · ชุด 15 ใบไม่กั้นปี weight 1 = 3.85 ใบต่อชีวิต จากการ์ด 124 ใบ · weight 4 = 7.71
- `era:` ไม่ใช่ปีจริง: เทียบ protoYear สุ่มต่อ seed · `years` คือปีจริง
- กันไว้: ไม่ใช้ชื่อตัวละคร ชื่อหนัง ชื่อแบรนด์ · ไม่ล้อคนจริงที่เสียหาย ไม่ล้อโศกนาฏกรรม · เว้นวัย ≤4 เว้นแต่ผู้รวมงานบอกต่าง · มีตัวเลือกปั่นอย่างน้อย 1 ข้อ

## วิธีวัด (repo อ่านอย่างเดียว)

ทำใน scratchpad ของ session ตัวเอง:

```bash
R=<scratchpad>/repo; mkdir -p "$R/node_modules"
cd <โฟลเดอร์ repo หลัก> && git fetch origin main && git archive origin/main | tar -x -C "$R"
cp -r node_modules/yaml "$R/node_modules/yaml"
cp <ร่าง>.yaml "$R/content/draft.yaml"; cd "$R"; npm run --silent lint:test > lint.log 2>&1; echo "exit $?"
```

วัดอัตราเจอ: เขียน `harness/reach.mjs` ในสำเนา ใช้ `playLife(mixSeed(1, i), content, randomBot, onCard)` นับ `card.kind === 'event'` ที่ id ขึ้นต้นด้วยคำนำหน้าของชุด · import จาก `../src/engine/index.mjs` `../src/node/load.mjs` `./bots.mjs` (`random`) · n=1000 พอ
