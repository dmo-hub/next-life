# ทดสอบผ่าน browser

## เตรียม

- `node build.mjs` ก่อนทุกครั้ง หน้าใน `docs/` ไม่ build เองตอนแก้ `src/`
- เปิด `docs/play.html` ตรงจากไฟล์ได้ แต่ service worker ไม่ลงกับ `file://` งานออฟไลน์หรือแคชต้องเปิดผ่าน http ในเครื่อง

  ```bash
  npx serve docs -l 4173
  ```

- เปิดเกมใหม่ทุกรอบด้วยสถานะสะอาด เกมเก็บเซฟใน `localStorage` คีย์ขึ้นต้น `next-life-`

  ```js
  Object.keys(localStorage).filter((k) => k.startsWith('next-life-')).forEach((k) => localStorage.removeItem(k));
  ```

## วัดอะไร

- อ่าน console ทุกรอบ error ต้องเป็น 0
- เล่นส่วนที่แก้จนเห็นผลบนจอ หน้าโหลดได้ไม่ได้พิสูจน์ว่าทำงาน
- งานหน้าจอถ่ายที่กว้าง 360 390 และ 1280
- ค่าที่ต้องการต่อเวลาหรือสุ่ม กดซ้ำหลายรอบ อย่าสรุปจากรอบเดียว

## กับดัก

- selector ตรงหลายตัวจะตก strict mode ให้จำกัดด้วย role ชื่อ หรือ `.first()` เมื่อรู้ว่าตัวแรกคือตัวที่ต้องการ
- ปุ่มที่เพิ่งขึ้นอาจยังเล่นแอนิเมชัน ให้รอสถานะ ไม่ใช่รอเวลาตายตัว
- `setOffline` ไม่พิสูจน์ service worker ให้ปิด server จริงแล้วเปิดซ้ำ
- ภาพจอเก็บนอก repo ยกเว้นใบระบุว่าต้องเพิ่มภาพ ไฟล์ทดสอบไม่เข้า PR
