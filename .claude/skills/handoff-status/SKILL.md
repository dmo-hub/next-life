# ส่งต่องาน

สถานะอยู่ที่คอมเมนต์ใน PR ของงาน ถ้ายังไม่มี PR ใช้ issue ของใบ ไม่สร้างไฟล์ใน repo งานเดิมอัปเดตคอมเมนต์เดิมหรือเติมต่อ ไม่แตกหลายที่

## ก่อนเขียน

ยิงสถานะสด อย่าใช้ความจำ

```bash
git branch --show-current
git status --short -uall
git log --oneline origin/main..HEAD
```

push branch ก่อน งานที่อยู่แค่ในเครื่องคนอื่นรับต่อไม่ได้ ของที่ยังไม่พร้อม commit ให้บอกชัดว่าอยู่ที่ไหน

## แม่แบบ

```markdown
## สถานะส่งต่อ <วันที่ เวลา>
branch: <ชื่อ> · sha: <สั้น> · ฐาน main: <สั้น>

### เสร็จแล้ว
### กำลังทำ
### ยังไม่ได้ทำ
### ด่านที่รันแล้ว
<คำสั่ง · ผล · sha ที่วัด>
### ไฟล์สำคัญ
### ข้อควรระวัง
### ขั้นตอนถัดไป
```

## กติกา

- เลขทุกตัวบอก sha ที่วัด เลขที่ไม่ได้วัดเขียนว่ายังไม่วัด
- ข้อที่เดาแยกจากข้อที่รู้
- ไม่ใส่ secret และ path ส่วนตัวในเครื่อง
- ปิดท้ายด้วย prompt 1 ก้อนให้คนรับต่อวางได้เลย บอกเลข PR branch และงานข้อแรก
