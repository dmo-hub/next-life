# ทำใบงาน

## ก่อนแก้ไฟล์แรก

1. อ่าน issue ให้จบ รวมคอมเมนต์ และอ่าน `next-life-contributor/SKILL.md` กับ `references/process.md`
2. บอก 1–2 บรรทัดว่าจะทำอะไรจากใบเลขไหน
3. บอกว่าจะวัดที่จุดไหน ถ้าใบไม่ได้ระบุ ถามก่อน อย่าเขียนโค้ดที่ไม่มีทางวัด
4. สร้าง branch `lane-<ชื่อคุณ>/<ชื่อใบ>` จาก `origin/main`

## ระหว่างทำ

- ทำแค่โจทย์ในใบ เจอของนอกใบให้เปิด issue ใหม่
- ถ้าเขียนทดสอบได้ ให้เขียนด่านที่ตกก่อน แล้วทำให้ผ่าน ทีละพฤติกรรม ทดสอบผ่านทางที่ผู้เล่นหรือด่านเรียกใช้จริง
- ตัวเลขเกมอยู่ใน `content/*.yaml` ค่าที่ไม่มีในใบห้ามตัดสินเอง ให้ถามใน issue
- เพิ่มไฟล์ใน `src/engine` ต้องเติม `files` ใน `build.mjs`
- `docs/*.html` มาจาก `node build.mjs` ไม่แก้มือ

## ปิดใบ

1. merge `origin/main` เข้า branch แล้วรันด่านตามชนิดงาน
2. เปิด `docs/play.html` เล่นส่วนที่แก้ console error ต้องเป็น 0
3. ไล่เกณฑ์รับงานทีละข้อ ใช้ `verify-code` ตรวจสิ่งที่จะรายงาน
4. commit ด้วยสกิล `commit`
5. เปิด PR กรอกแม่แบบครบ ใส่เลขด่านพร้อม sha ที่วัด

เลขที่วัดก่อน commit สุดท้ายต้องวัดใหม่ถ้าไฟล์เปลี่ยน ด่านตกให้บอกตามจริงใน PR
