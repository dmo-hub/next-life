# จุดพักงาน

สำรวจอย่างเดียว ไม่ commit และไม่รันสกิลถัดไปเองจนผู้ใช้เลือก

## สำรวจสด

```bash
git branch --show-current
git status --short -uall
git log --oneline origin/main..HEAD
git rev-list --count HEAD..origin/main
```

แล้วเปิด issue ของใบ ไล่เกณฑ์รับงานว่าข้อไหนจบ

## สรุป

```
branch: <ชื่อ> · ตาม main อยู่ <N> commit
ของในใบ: <ไฟล์>
ของนอกใบ: <ไฟล์ หรือ ไม่มี>
เกณฑ์รับงาน: <จบ N จาก M>
ด่าน: <ที่รันแล้วและ sha หรือ ยังไม่รัน>
```

ไฟล์ที่ไม่ได้แก้เองในรอบนี้ไม่นับเป็นของในใบ ให้ถามก่อน

## เลือกขั้นถัดไป

ถามผู้ใช้ เลือกได้หลายข้อ ตัดข้อที่ไม่เกี่ยว

- `verify-code` เมื่อมีโค้ดที่ยังไม่ตรวจ
- `commit` เมื่อตรวจแล้ว
- เปิด PR เมื่อเกณฑ์รับงานจบครบ
- `retro` เมื่อเจอบทเรียนที่คนอื่นควรรู้
- `handoff-status` เมื่อยังไม่จบแต่จะหยุด

ทำตามลำดับนี้ ข้อไหนตกให้หยุดแล้วบอกผู้ใช้
