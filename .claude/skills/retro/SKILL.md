# ทบทวนหลังจบงาน

เอาเฉพาะบทเรียนที่ทำให้งานหน้าดีขึ้น อย่าเล่าสิ่งที่อ่านจาก git ได้อยู่แล้ว

## ขั้นตอน

1. ไล่ดูงานรอบนี้ ทางที่พลาด ด่านที่ไม่จับ สิ่งที่เอกสารบอกผิด คำถามที่ถามซ้ำ
2. เขียนบทเรียนละ 1 บรรทัด เหตุ ผล และทางกัน
3. เช็กว่าเอกสารเดิมมีแล้วหรือยัง ใน `CONTRIBUTING.md` และสกิล `next-life-contributor`
4. จัดประเภทตามตาราง
5. ยื่นรายการให้ผู้ใช้เลือก ข้อที่เลือกค่อยทำ

| บทเรียน | ไปที่ |
|---|---|
| ใช้ในเครื่องผู้ใช้คนเดียว | ความจำส่วนตัวของผู้ใช้ |
| ทุกคนที่ส่งงานต้องรู้ | issue เสนอแก้ `CONTRIBUTING.md` หรือสกิล |
| เป็นกฎที่เครื่องจับได้ | issue เสนอด่านหรือ hook |
| เกี่ยวกับดีไซน์เกม | issue ให้เจ้าของเคาะ |

## กติกา

- แก้ไฟล์ร่วมเป็นใบของตัวเอง ไม่แถมใน PR เกม
- เขียนว่าเกิดอะไรจริง พร้อมอาการหรือคำสั่งที่เห็น
- ถ้ากฎเดิมมีแล้วแต่ยังพลาด เสนอให้เครื่องจับแทนการเพิ่มคำเตือน
