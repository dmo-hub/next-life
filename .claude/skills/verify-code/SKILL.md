# ตรวจงานก่อนส่ง

ขั้นนี้อ่านและรันด่านเท่านั้น ของที่เจอแก้เป็นงานถัดไป แล้วตรวจซ้ำ

ขอบเขตคือไฟล์ที่แก้ในใบนี้

| ข้อ | ตรวจ | ทำอย่างไร |
|---|---|---|
| 1 | ด่านสด | รันด่านตามชนิดงานใน `next-life-contributor/references/process.md` บน sha ปัจจุบัน อ่านผลจริง ไม่ใช้ผลเก่า |
| 2 | คำกล่าวอ้าง | ทุกข้อที่จะรายงาน ติดป้าย `วัดแล้ว <คำสั่ง>` หรือ `อ่านโค้ด` หรือ `เดา` ข้อที่เดาต้องบอกว่าเดา |
| 3 | ครบตามใบ | เปิด issue ไล่เกณฑ์รับงานทีละข้อ ข้อที่ขาดบอกว่าขาด |
| 4 | ของหลุด | อ่าน diff หา secret คำสั่ง debug ไฟล์นอกใบ และไฟล์ต้องห้ามในสกิล `commit` |
| 5 | เปิดจริง | `node build.mjs` แล้วเปิด `docs/play.html` เล่นส่วนที่แก้ console error ต้องเป็น 0 |

## ตัดสิน

- ข้อ 1 ตก หรือข้อ 4 เจอ secret หยุด ไม่ commit
- ข้ออื่นยังไม่ครบ ไปต่อได้ แต่ต้องบอกในรายงานและในเนื้อ PR
- ไฟล์เปลี่ยนหลังตรวจ ผลตรวจเดิมใช้ไม่ได้

## รายงาน

ตาราง 5 ข้อ ผ่านหรือตก พร้อมหลักฐาน 1 บรรทัดและ sha ที่วัด ตามด้วยข้อที่ยังไม่ได้ตรวจ แต่ละบรรทัดบอกว่าลองทางไหนแล้วได้ผลอะไร อย่าเดาสาเหตุ

ด่านผ่านทั้งที่ควรตกก็เป็นไปได้ ถ้าแก้โค้ดแล้วเลขไม่ขยับเลย ให้ลองทำให้ตกหนึ่งครั้งเพื่อพิสูจน์ว่าด่านวัดของจริง
