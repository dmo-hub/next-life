# ศัพท์ของเกม

ใช้คำเดียวกันทั้งใน issue โค้ด และหน้าจอ คำที่ลอยทำให้ข้อเสนอคนละเรื่องกันโดยไม่รู้ตัว

## อ่านก่อน

`GDD.md` และ `design/<เรื่อง>/decisions.md` คือที่มาของคำ `design/` อ่านอย่างเดียว อย่าแก้

## ระหว่างคุย

- คำของผู้ใช้ขัดกับเอกสาร บอกทันที "GDD เรียกสิ่งนี้ว่า X คุณหมายถึง X หรือคนละอย่าง"
- คำกว้างหรือซ้อนความหมาย เสนอคำเดียวที่ชัด
- ลองด้วยกรณีจริง คิดเหตุการณ์ขอบที่บังคับให้เส้นแบ่งชัด
- เทียบกับโค้ด ถ้าโค้ดทำต่างจากที่พูด ยกขึ้นมาถาม อย่าเลือกข้างเอง

## บันทึกคำ

repo นี้ไม่มีไฟล์ศัพท์กลาง อย่าสร้าง `CONTEXT.md` หรือ `docs/adr/` เอง

- คำที่ตกลงในใบ เขียนใน issue ของใบ หัว "ศัพท์"
- คำใหม่ที่ควรใช้ทั้งเกม เสนอเป็นหัว "ต้องให้เจ้าของเคาะ"
- ชื่อในโค้ดใช้คำเดียวกับที่ตกลง ข้อความบนจอเป็นภาษาผู้เล่น
