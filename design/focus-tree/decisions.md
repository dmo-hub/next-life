- 183 ชนิดเกณฑ์ปลดพิเศษ: **"ในกลุ่ม + ข้ามกลุ่ม (แนะนำ)"** — ปลดในกลุ่มตัวเองถึง N โหนด **และ** ปลดในกลุ่มคู่ถึง M โหนด · กลุ่มคู่ = กลุ่มในสายเดียวกันหรือคู่คอมโบ (คำอธิบายตัวเลือก · ยังไม่ได้เลือกระหว่างสองแบบ ⇒ หน้า tweak ให้สลับดู) · ตัวเลือกที่ยื่น: ในกลุ่ม + ข้ามกลุ่ม / ในกลุ่มอย่างเดียว / ข้ามกลุ่มอย่างเดียว
