**อายุขัยเผ่า**: เอลฟ์ Frieren "มีชีวิตเกินพันปี" ไม่มีตัวเลขเผ่าอื่นให้ [อ่านจากแหล่ง] https://en.wikipedia.org/wiki/Frieren_(character) · เผ่า Migurd ใน Mushoku "อ่อนเยาว์และอายุยืน" ไม่มีตัวเลข https://en.wikipedia.org/wiki/List_of_Mushoku_Tensei_characters · ตัวเลขอายุขัย เอลฟ์/คนแคระ/มนุษย์ ของเรื่องใด: หาไม่เจอ → ตั้งเองได้ [ความเห็น]

**ทางเลือกสำหรับ popup (ช่วงวัยต่างโลก)**
1. ใช้ 5 ค่าเดิม + ทอง: ข้อดี ผู้เล่นคุ้นมือ ด่าน harness เดิมใช้ได้ · ข้อเสีย แนวเกมต่างจากชาติไทยไม่ชัด
2. ชุดต่างโลก (HP · มานา · เสน่ห์ · โชค · ทอง): ข้อดี สลับโหมดแล้วรู้สึกต่าง · ข้อเสีย สมดุลและด่านต้องทำใหม่ (ใน MAP ยังไม่ตัดสิน)
3. ผสม: คงสุขภาพ/ความสัมพันธ์ แล้วเติมมานา+ทอง: ข้อดี ต่อยอดโค้ดเดิมได้ · ข้อเสีย ต้องอธิบายผู้เล่น
แนะนำ 3 [ความเห็น]: ทั้ง Mushoku, Bookworm, Frieren ที่อ่านมา ไม่มีหน้าต่างสถานะเป็นตัวเลขหลัก (ต่างจาก Re:Zero/Slime) การไม่เปิดตัวเลขเยอะจึงไม่ขัดกับเรื่องที่ชีวิตเต็ม
ช่วงวัย: ใช้ 3 ขั้น เด็ก (จำชาติก่อนได้ ฝึกเวท) · วัยผจญภัย · สูงวัย (ตามโครง Mushoku เด็ก→หนุ่ม และ Frieren เพื่อนแก่ตาย) [ความเห็น]
สาเหตุตาย: ชรา / ศึกใหญ่ / ธรรมชาติตามเผ่า · เอลฟ์ตายช้ามากจึงเป็น "รุ่นที่เห็นเพื่อนมนุษย์ตาย" แทนการเล่นจนจบ [ความเห็นจาก Frieren]
