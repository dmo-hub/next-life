## Decisions so far

- (ตั้งแผนที่ · popup 2026-11-02) ค่าซ้อนทับเดียวต่อเซฟ นับการข้ามโลกทั้งเซฟ เริ่มเพิ่มทีละนิดตั้งแต่เหยียบซ้ำครั้งแรก · **ขึ้นอย่างเดียว** ไม่มีทางลด
- (ตั้งแผนที่) โทนโลกปกติเป็นขั้น: เบา (เห็นแค่ตัวเรา · ข่าวลือ) → ถึงเกณฑ์เปิดเผยทั้งสังคม
- (ตั้งแผนที่) รั่วครบ 4 ทิศ: ต่างโลก→ไทย (เกต หอคอย ดันเจียน มอนสเตอร์) · หลังตาย→ไทย/ต่างโลก (ผี วิญญาณ) · ต่างโลก→หลังตาย (มอนสเตอร์บุกนรก) · ไทย→ต่างโลก (คนหลงมิติ ของใช้ อาคาร ความรู้/ความเชื่อ)
- (ตั้งแผนที่) บทผู้เล่นในโลกปกติ = เหตุการณ์แทรก + อาชีพใหม่ + เกมย่อยดันเจียน **ระบบใหม่ในโลกปกติ** (ไม่ยืมระบบต่างโลก)
- (ตั้งแผนที่) ผีที่โผล่ = ทั้งคนจริงจากชาติก่อนและผีทั่วไป
- (ตั้งแผนที่) ขั้นสุด = เหตุการณ์จบโลก → เริ่มรอบใหม่ เก็บกรรม+สมุด
