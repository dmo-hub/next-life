# thai-life — เกมจำลองชีวิตคนไทยหลายรุ่น

สถานะ: **กำลังออกแบบ** ยังไม่มีตัวเกม · เว็บ: https://dmo-hub.github.io/thai-life/

เกิดแบบสุ่มเป็นคนไทยปี 2500–2569 ตามสถิติจริง ใช้ชีวิต 15–20 นาที ตายแล้วไปศาลพญายม เปิดบัญชีบุญบาป แล้วเล่นต่อเป็นลูกหลานหรือเกิดใหม่ตามกรรม

## โครง repo

| path | คืออะไร |
|---|---|
| `docs/index.html` | หน้าแรก (GitHub Pages เสิร์ฟจาก `docs/`) |
| `docs/overview.html` | ภาพรวมการออกแบบ สร้างจาก `docs/spec/` |
| `docs/cards.html` | ต้นแบบหน้าตาการ์ด |
| `docs/spec/MAP.md` | แผนที่การออกแบบ: จุดหมาย · คำตัดสิน · เรื่องที่ยังไม่ชัด |
| `docs/spec/tickets/` | ใบตัดสินใจทีละเรื่อง พร้อมคำตอบ |
| `docs/spec/lore-*.md` · `lore-finance-series.html` | รีเสิร์ชพร้อมแหล่งอ้างอิง |

`docs/spec/` เป็นสำเนาของแผนที่การออกแบบ ต้นฉบับแก้ที่อื่นแล้วคัดลอกมาทับ อย่าแก้ไฟล์ในนี้ตรง ๆ

ข้อมูลการเงินในรีเสิร์ชเป็นข้อมูลเพื่อออกแบบเกม ไม่ใช่คำแนะนำการลงทุน
