# next-life — ชาติหน้า · Next Life

สถานะ: **กำลังออกแบบ** ยังไม่มีตัวเกม · เว็บ: https://dmo-hub.github.io/next-life/

เกิดแบบสุ่มเป็นคนไทยปี 2500–2569 ตามสถิติจริง ใช้ชีวิต 15–20 นาที ตายแล้วไปศาลพญายม เปิดบัญชีบุญบาป แล้วเล่นต่อเป็นลูกหลานหรือเกิดใหม่ตามกรรม

## โครง repo

| path | คืออะไร |
|---|---|
| `docs/index.html` | หน้าแรก (GitHub Pages เสิร์ฟจาก `docs/`) |
| `docs/overview.html` | ภาพรวมการออกแบบ สร้างจาก `docs/spec/` |
| `docs/cards.html` | ต้นแบบหน้าตาการ์ด |
| `docs/spec/MAP.md` | แผนที่การออกแบบ: จุดหมาย · คำตัดสิน · เรื่องที่ยังไม่ชัด |
| `docs/spec/tickets/` | ใบตัดสินใจทีละเรื่อง พร้อมคำตอบ |
| `docs/spec/lore-*.md` · `lore-finance-series.html` | รีเสิร์ชพร้อมแหล่งอ้างอิง |

| `data/*.json` | ข้อมูลยุคจริง (เกิด · เงินเฟ้อ · e0/อัตราตายทารก · พฤติกรรมเสี่ยง · ไทม์ไลน์ · จุดเกิด: ประชากรรายภาค/ส่วนแบ่งรายได้/รายได้ครัวเรือนรายภาค) ทุกค่ามี `source` หรือ `assumption: true` + `note` |
| `scripts/fetch-data.mjs` | ดึงข้อมูล World Bank / WHO มาเขียน `data/` ใหม่ (ต้องต่อเน็ต) · ไฟล์ `habits-survey.json` · `era-events.json` · `birthplace.json` เขียนมือ |
| `scripts/check-data.mjs` | ตรวจว่าตัวเลขทุกตัวใน `data/` มี source หรือ assumption ครอบ (ยกเว้นป้ายปี/อายุ) และเหตุการณ์ทุกตัวบอกที่มาของช่วงปี |
| `content/*.yaml` | เนื้อหาเหตุการณ์ (schema ใบ 07 + ส่วน `belief:` ใบ 12) — build และ harness โหลดผ่านด่าน `src/node/lint/` ไม่ผ่าน = ปฏิเสธทั้งชุด รายงานทุกข้อรูป `<ไฟล์> · <id>[path] · <กติกา>: <อธิบาย>` |
| `content/rules/banned.yaml` | คำต้องห้าม (regex + เหตุผล + ตัวอย่าง bad/ok ที่ `lint:test` ตรวจ) — จับได้ไม่ครบโดยตั้งใจ เจ้าของยังต้องอ่าน |
| `data/system-starts.json` | ปีที่ระบบ/สินทรัพย์เริ่มมีจริง (หุ้น · กยศ. · พร้อมเพย์ …) · `closed` = ปีเริ่มยังไม่ยืนยัน เหตุการณ์อ้างไม่ได้ |
| `content-fixtures/` | `bad/<กติกา>.yaml` ผิดทีละกติกา · `good/` ตัวอย่าง 3 ตัวของใบ 12 + ไฟล์ใช้ทุกฟิลด์ — อยู่นอก `content/` จึงไม่เข้าเกม |
| `content-fixtures/harness/` | เนื้อหาทดสอบบัญชีบุญบาป (ติดป้ายบุญ/บาป · วงจรบนบาน) ที่ `npm run merit` โหลดเพิ่ม — ไม่เข้าเกม |
| `src/engine/finance.mjs` · `data/finance.json` | การเงิน (B08): ผลตอบแทนจริงรายปี เงินฝาก/หุ้นไทย/ทอง/ที่ดิน · ปีอนาคตใช้ปีต้นแบบร่วมกับเงินเฟ้อ · ค่าจ้างตามอาชีพ (ILOSTAT 2561) × ดัชนีค่าแรงขั้นต่ำ × ภาค · การ์ดจัดสรรทุก 5 ปี (อายุ 20–70) · ฐานะเกิด 10 ระดับ (decile) · `effects.invest` ต้องประกาศ `systems` ของสินทรัพย์ (ด่าน `asset-system`) |
| `src/engine/merit.mjs` | บัญชีบุญบาปซ่อน: ตารางน้ำหนักกลาง · ตัวคูณกรรมต่อโอกาสตาย · ลางดี/ลางร้าย · ด่านตาราง (vow_broken ต้องเบากว่าระดับ 1 ทุกหมวด) ที่ `loadEvents()` และ `lint:test` เรียก |

คำสั่ง: `npm run build` · `npm run bump` (เลขเวอร์ชันเดโมบนหัว play.html: patch +1 · `npm run bump -- minor` = minor +1 · เขียนวันที่ build แล้ว build ต่อ — รันก่อน commit ที่จะขึ้น Pages) · `npm run sim` (1,000 ชีวิต) · `npm run gate` (20,000 ชีวิต: ด่าน 3a ตารางชีพที่เกมใช้ตรง e0/อัตราตายทารกจริงรายปี · ด่าน 3b อายุเฉลี่ยบอทสุ่ม ±3 ปีจากอายุตายที่ข้อมูลคาดตามแนวชีวิต · ด่าน 4 ชีวิตที่ตายหลัง 60 ≥90% ยาว 70–150 การ์ด · ค่าแถบอยู่ใน 0–100 ทุกการ์ด) · `npm run merit` (บอทสุ่ม/สายบุญ/สายบาป 20,000 ชีวิตต่อบอทบนเนื้อหาจริง + `content-fixtures/harness/`: บัญชีสองสายแยกกัน · ธง vow_broken ตั้งได้ · การ์ดไม่มีค่าบัญชี · `--no-karma` = ตัวควบคุมปิดตัวคูณกรรม) · `npm run finance` (50,000 ชีวิต ~3 นาที — 20,000 มัธยฐานฐานะติดกันสลับได้จากสุ่ม: ทรัพย์สุทธิตอนตายเรียงตามฐานะ 10 ระดับ + ทุกทศวรรษเกิด · บน/ล่าง และ กทม./อีสาน ทิศเดียวกับ SES · ตัวควบคุมปิดผลจุดเกิดแล้วช่องว่างต้องหด · รันซ้ำผลเดิม) · `npm run fetch:finance` (ต่อเน็ต เขียน `data/finance.json` ไฟล์เดียว) · `npm run check:data` · `npm run lint:test` (ไฟล์ bad ทุกไฟล์ต้องตกด้วยกติกาตามชื่อไฟล์เท่านั้น · good ผ่าน · ทุกกติกามีไฟล์ทดสอบ · `content/` จริงผ่าน)

`docs/spec/` เป็นสำเนาของแผนที่การออกแบบ ต้นฉบับแก้ที่อื่นแล้วคัดลอกมาทับ อย่าแก้ไฟล์ในนี้ตรง ๆ
