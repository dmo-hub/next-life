# เกิดใหม่ทั้งที ชาตินี้ขอชิงมาเกิด · Next Life

เกมการ์ดชีวิตคนไทย เกิดแบบสุ่มปี 2500–2569 ตามสถิติจริง ใช้ชีวิตหนึ่งชาติราว 15–20 นาที ตายแล้วไปปรโลก เปิดบัญชีบุญบาป แล้วเล่นต่อเป็นลูกหลาน เกิดใหม่ตามกรรม หรือข้ามไปต่างโลก

- **เล่นเลย:** https://dmo-hub.github.io/next-life/play.html
- **เว็บของเกม:** https://dmo-hub.github.io/next-life/ (วิธีเล่น · แพตช์โน้ต · กลไก · การ์ดทั้งหมด)
- **อยากช่วยทำ:** เริ่มที่[ห้องผู้พัฒนา](https://dmo-hub.github.io/next-life/dev/index.html)
- **ภาพรวมการออกแบบ:** [GDD.md](GDD.md)

สถานะ: เล่นได้ครบวงจรหลายรุ่น ยังเพิ่มระบบอยู่ · ของที่กำลังทำดูหัว "กำลังทำ" ใน[แพตช์โน้ต](https://dmo-hub.github.io/next-life/whatsnew.html)

## เริ่มใช้งาน

ใช้ Node.js 22 (รุ่นที่ทดสอบอยู่)

```bash
npm install
npm run build        # สร้าง docs/play.html และหน้าเว็บจาก src/ + content/
```

เสิร์ฟโฟลเดอร์ `docs/` ด้วยเซิร์ฟเวอร์ใดก็ได้ (เช่น `npx serve docs`) แล้วเปิด `play.html`

## ก่อนส่งงาน

แก้อะไรก็ตาม รันชุดนี้ให้ผ่านก่อน (รวมราว 5 นาที):

| คำสั่ง | ตรวจอะไร |
|---|---|
| `npm run build` | สร้างเกมและหน้าเว็บใหม่ |
| `npm run lint:test` | เนื้อหาการ์ดผ่านกติกา · ไฟล์ตัวอย่างผิดต้องตกตามชื่อ |
| `npm run harness:test` | ตัวทดสอบเองยังจับของผิดได้ |
| `npm run site:check` | ตัวเลขบนเว็บตรงข้อมูล · ลิงก์ไม่ตาย · การ์ดครบ |
| `npm run check:data` | ตัวเลขทุกตัวใน `data/` มีแหล่งอ้างอิง |
| `npm run keep` | เซฟของผู้เล่นจากรุ่นก่อนยังโหลดได้ |

ถ้าแก้ engine เนื้อหาการ์ด หรือค่าสมดุล ต้องผ่าน `npm run full` ด้วย (จำลอง 20,000 ชีวิต × บอท 6 บุคลิก ราว 40 นาที) — คนรวมงานรันให้ตอนยกขึ้น `main`

## หาไฟล์

| อยากแก้ | ไปที่ |
|---|---|
| ตัวเกม (หน้าจอ ปุ่ม เอฟเฟกต์) | `src/ui/` — **อย่าแก้ `docs/play.html` ตรง** build สร้างให้ |
| กติกาเกม (อายุ เงิน กรรม ปรโลก ต่างโลก) | `src/engine/` |
| เนื้อหาการ์ด | `content/*.yaml` · คำต้องห้ามอยู่ `content/rules/banned.yaml` |
| ข้อมูลยุคจริง (เกิด เงินเฟ้อ อายุขัย เหตุการณ์) | `data/*.json` — ทุกค่าต้องมี `source` หรือ `assumption: true` + `note` |
| หน้าเว็บเขียนมือ | `docs/index.html` · `about.html` · `worlds.html` · `otherworld.html` · `whatsnew.html` — ตัวเลขใน `data-fact` build ฉีดให้ |
| หน้าเว็บที่ build สร้าง | `catalog.html` · `spoilers.html` · `guide.html` — แก้แม่แบบใน `src/site/` |
| ตัวทดสอบและบอทจำลอง | `harness/` (อ่านหัวไฟล์แต่ละตัว) · `content-fixtures/` ตัวอย่างผิด/ถูก ไม่เข้าเกม |
| ห้องผู้พัฒนา | `docs/dev/` |

โฟลเดอร์อ่านอย่างเดียว:

- `design/` คำตัดสินการออกแบบ คัดลอกจากต้นฉบับนอก repo ทุกครั้งที่ปล่อยรุ่น อยากเปลี่ยนให้เปิด issue
- `docs/spec/` แผนที่การออกแบบชุดเก่า และรีเสิร์ชพร้อมแหล่งอ้างอิง
- `docs/archive/` หน้าเก่าเก็บไว้อ้างอิง

## ปล่อยรุ่นใหม่

```bash
npm run rel -- <notes.json> [worktree]
```

เขียนโน้ตรุ่นลงแพตช์โน้ต → เลื่อนเลขเวอร์ชัน → เลื่อนฐานด่าน `keep` → commit (ไม่ push ไม่ tag)

```json
{ "tag": "<ชื่อขบวน>", "shas": ["<commit ที่ปล่อย>"], "note": ["ข้อละบรรทัด เขียนเป็นภาษาผู้เล่น"] }
```

- merge ไว้แล้วใช้ `NOPICK=1` · ลองดูก่อนเขียนจริงด้วย `DRY=1`
- ก่อนรัน ลบข้อที่ปล่อยแล้วออกจากหัว "กำลังทำ" ใน `docs/whatsnew.html` เอง
- รายละเอียดอยู่หัวไฟล์ `scripts/rel.mjs`

## คำสั่งอื่น

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `npm run sim` | จำลอง 1,000 ชีวิต ดูผลเร็ว ๆ |
| `npm run gate` | 20,000 ชีวิต: อายุตายตรงตารางชีพจริง · ความยาวชีวิต · ค่าแถบไม่หลุด 0–100 |
| `npm run full` | ชุดเต็มก่อนขึ้น main · `-- --seed2 N` รันซ้ำ seed เดิม · `full:release` 100,000 ชีวิต |
| `npm run merit` · `lineage` · `finance` · `belief` · `titles` | ด่านเฉพาะระบบ: บุญบาป · ข้ามรุ่น · การเงิน · สายมู · ฉายา |
| `npm run lifehash` | เทียบผลเล่นก่อน/หลังแก้ ว่าเปลี่ยนแค่ที่ตั้งใจ |
| `npm run shots` | ถ่ายภาพหน้าจอเว็บใหม่ + ตรวจล้นจอ 390/1280 (ต้องมี playwright-core) |
| `npm run fetch:data` · `fetch:finance` | ดึงข้อมูล World Bank / WHO ใหม่ (ต้องต่อเน็ต) |
| `npm run bump` | เลื่อนเลขเวอร์ชันบนหัวเกม (`-- minor` = เลขกลาง) |

คำสั่งที่เหลือใน `package.json` (`overlap` · `continuity` · `isekai` · `family` · `causes` ฯลฯ) อ่านหัวไฟล์ใน `harness/` ของแต่ละตัว
