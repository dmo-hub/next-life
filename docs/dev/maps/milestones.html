ตอนจบ (ร่าง · สูงสุด 3 สาย)

    ชื่อตอนจบตามหลักไมล์สูงสุด เรียงสายที่ไปไกลสุดก่อน · ถึงปลายสาย = ชื่อพิเศษของสาย

    ถึงแล้วต่อสาย

    กติกา (รอบ 20)

    • คลิกหลักไมล์ = ถึงขั้นนั้น · คลิกขั้นที่ถึงล่าสุดซ้ำ = ถอยหนึ่งขั้น
    • ไม่มีป้ายบนการ์ด — ดูหลักไมล์จากหน้ารวมอย่างเดียว
    • ถึงปลายสาย → ชื่อเสียงตระกูล +1
    • หลักไมล์ = แต้มในร้านบุญหลังตาย
    ยังไม่ได้ตัดสิน: ชื่อตอนจบพิเศษต่อสาย · สเกลแต้มร้านบุญต่อหลักไมล์
