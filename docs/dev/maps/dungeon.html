กติกา (รอบ 22)

  • เข้าครั้งเดียวยาวจนจบ 5–10 ชั้น + บอส
  • ชั้นละการ์ด: กับดัก / สมบัติ / มอนสเตอร์ · เสีย hp
  • ถอยออกได้ทุกชั้น เก็บของที่ได้ · เข้าใหม่เริ่มชั้น 1
  • ลึกขึ้น เสี่ยงตายมากขึ้น ของดีขึ้น · ตายในดันเจียนได้
  • บอสให้หินเทเลพอร์ตไปได้ทุกแคว้น (ใช้ใบละครั้ง)
ยังไม่ได้ตัดสิน: เนื้อการ์ดชั้น/บอส · รางวัลต่อความลึก — หน้านี้จึงมีแค่ป้ายชนิดห้อง
