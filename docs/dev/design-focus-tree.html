Problem Statement

ระบบโฟกัสชีวิตตอนนี้เป็นรายการโฟกัส 21 ตัว เลือกได้ทีละตัวตามช่วงวัย มีสายต่อ 9 คู่ และประตู 5 สายที่ซ่อนตัวเลือกจนสะสมปีครบ ผู้เล่นเห็นเป็นรายการแบนเดียว ไม่เห็นเส้นทางชีวิตที่ปูมา ปีที่ทุ่มไปแล้วไม่ทิ้งร่องรอยติดตัวนอกจากตัวนับ ไม่มีทางแยกให้เลือก ไม่มีรูปทรงชีวิตให้ดูย้อน เจ้าของต้องการให้ "ระบบโฟกัสชีวิต" เป็นแนว Passive Tree: โหนดต่อกันเป็นเส้นทาง ปลดทีละโหนด เลือกทางแยก แล้วของที่ปลดติดตัวไปทั้งชีวิตและส่งต่อทายาทบางส่วน

Solution

ต้นไม้ต้นเดียวทั้งชีวิต 5 แขนง (เงิน · ความสัมพันธ์ · ความรู้ · ทักษะ · ลึกลับ) ~40 โหนด (ข้อ 76 81 14 49) ผู้เล่นทุ่มปีเต็มเข้าโหนดที่กำลังจะปลดทีละโหนด ระหว่างทุ่มได้ผลรายปีเต็มของโหนด ปลดแล้วเหลือผลเบาถาวร + ตัวเลือกใหม่บนการ์ดเดิม + การ์ดหมวดนั้นออกบ่อยขึ้น (ข้อ 1 5 20) โหนดเล็กปลดเมื่อปีครบและตอบการ์ดหมวดตรงแขนงครบจำนวน · โหนดใหญ่ปลดผ่านการ์ดด่านของตัวเองซึ่งให้เลือกผล 2–3 ทาง (ข้อ 9 45 64) จอแท็บโฟกัสเปลี่ยนจากรายการเป็นภาพต้นไม้ ดูทีละแขนง + ต้นเต็มเลื่อน/ซูม (ข้อ 12 47ก) ผลบนจอยังบอกเป็นคำ ไม่มีตัวเลข (หลอดไม่มีตัวเลข + คำบอกขั้น · ข้อ 10 46) รอบนี้ลงเฉพาะโลกหลัก ต่างโลก/ปรโลกเดินแบบเดิม (ข้อ 40) ใบแรกคือเลนร่างต้นไม้ ~40 โหนดเป็นหน้า HTML ให้เจ้าของเคาะก่อนลงเนื้อ (ข้อ 22)

User Stories

ผู้เล่น · โครงต้นไม้

  1. As a ผู้เล่น, I want ต้นไม้ต้นเดียวทั้งชีวิต 5 แขนง (เงิน · ความสัมพันธ์ · ความรู้ · ทักษะ · ลึกลับ), so that เห็นชีวิตทั้งชีวิตเป็นเส้นทางเดียว (ข้อ 76 81)
  2. As a ผู้เล่น, I want ต้นไม้ ~40 โหนด (แขนงละ ~10) ตั้งแต่แรก, so that มีทางให้เดินพอทั้งชีวิต (ข้อ 14 49)
  3. As a ผู้เล่น, I want โหนดออกแบบใหม่ทั้งหมด ใหม่หมดทั้งชื่อ, so that ต้นไม้ไม่ใช่รายการเดิมที่ย้ายที่ (ข้อ 3 41)
  4. As a ผู้เล่น, I want ทางแยกไม่ล็อก เวลาเป็นราคา, so that ไปแขนงอื่นได้แต่ต้องจ่ายด้วยปีชีวิต (ข้อ 8)
  5. As a ผู้เล่น, I want บางแขนงกลับมาบรรจบกันได้, so that ทางอ้อมพาไปถึงโหนดเดียวกันได้ (ข้อ 21 37)
  6. As a ผู้เล่น, I want ประตูอยู่ลึก 2–3 โหนด และปลายแขนงเป็นโหนดต่อยอด/keystone, so that ประตูไม่ใช่ปลายทางสุดท้าย (ข้อ 37)
  7. As a ผู้เล่น, I want ทุกวัยมีโหนดให้ทุ่มอย่างน้อย 1 ต่อแขนง, so that ไม่มีช่วงวัยที่ต้นไม้ตาย (ข้อ 44)

ผู้เล่น · จุดเริ่ม

  1. As a ผู้เล่น, I want เกิดที่ต้นแขนงตามฐานะ/ครอบครัว, so that ชีวิตเริ่มต่างกันตามที่เกิด (ข้อ 15)
  2. As a ผู้เล่น, I want เริ่มได้แขนงเดียว ตามลำดับ ฐานะ > อาชีพ > แขนงพ่อแม่, so that จุดเริ่มชัดไม่ซ้อน (ข้อ 39)
  3. As a ผู้เล่น, I want จุดเกิดดูอาชีพพ่อแม่ด้วย, so that ลูกชาวนากับลูกข้าราชการเริ่มต่างกัน (ข้อ 17)

ผู้เล่น · ทุ่มและปลด

  1. As a ผู้เล่น, I want ทุ่มโหนดที่กำลังจะปลด (ปีเต็มเข้าหลอดโหนดนั้น), so that รู้ว่าปีนี้ลงกับอะไร (ข้อ 20)
  2. As a ผู้เล่น, I want ระหว่างทุ่มได้ผลรายปีเต็มของโหนด ปลดแล้วเหลือผลเบาถาวร, so that การทุ่มมีผลทันทีและทิ้งร่องรอย (ข้อ 20)
  3. As a ผู้เล่น, I want ทุ่มได้แค่โหนดที่ยังไม่ปลด, so that ไม่วนทุ่มโหนดเดิม (ข้อ 36)
  4. As a ผู้เล่น, I want ปลดแล้วเลื่อนไปโหนดถัดไปเอง ไม่เสียปี และเปลี่ยนเองทีหลังได้โดยไม่เสียปี, so that ไม่ต้องกดทุกครั้งที่ปลด (ข้อ 43)
  5. As a ผู้เล่น, I want แต่ละโหนดมีแต้มในการปลดโหนดถัดไปไม่เท่ากัน (ปีเต็ม + ต้องผ่านเหตุการณ์), so that โหนดลึกยากกว่าโหนดตื้น (ข้อ 7)
  6. As a ผู้เล่น, I want โหนดเล็กปลดเมื่อตอบการ์ดหมวดตรงแขนงครบจำนวน (ข้อไหนก็นับ), so that เล่นตามปกติก็คืบ (ข้อ 9 45)
  7. As a ผู้เล่น, I want โหนดใหญ่ (ปลายแขนง/ประตู) มีการ์ดด่านของตัวเอง 1 ใบโผล่เมื่อปีครบ, so that โหนดสำคัญมีฉากของมัน (ข้อ 9)
  8. As a ผู้เล่น, I want เลือกผล 2–3 ทางบนการ์ดด่านของโหนดใหญ่, so that โหนดเดียวกันพาไปคนละทาง (ข้อ 32 64)
  9. As a ผู้เล่น, I want ตัวเร่ง/ชะลอการปลด (ครู · ฐานะ · นิสัยใฝ่รู้ · ยิ่งแก่ยิ่งช้า), so that วัยและที่เกิดมีผลต่อความเร็ว (ข้อ 24 57)
  10. As a ผู้เล่น, I want เลือกครู/ที่ปรึกษาเป็นตัวเลือกในด่านจบประถม, so that มีตัวเร่งจากการเรียนโดยไม่เพิ่มการ์ด (ข้อ 27 59)

ผู้เล่น · ผลติดตัว

  1. As a ผู้เล่น, I want โหนดที่ปลดให้ตัวเลือกใหม่บนการ์ดเดิม, so that ของที่ฝึกมาเปิดทางในเรื่องราว (ข้อ 1 5)
  2. As a ผู้เล่น, I want การ์ดหมวดของแขนงที่ปลดมากสุดออกบ่อยขึ้นถาวร, so that ชีวิตเอียงไปทางที่เลือก (ข้อ 5 42)
  3. As a ผู้เล่น, I want ผลรายปีเบาถาวรจากโหนดที่ปลด, so that ของที่ฝึกยังติดตัว (ข้อ 5)
  4. As a ผู้เล่น, I want โหนดเอียงโอกาสสำเร็จบนตัวเลือกเดิมตามหมวดการ์ด โดยป้ายยังเป็น "สำเร็จ ~X%" เดิม, so that ทักษะช่วยจริงแต่จอไม่รก (ข้อ 25 58)
  5. As a ผู้เล่น, I want โอกาสทำงาน สอบเข้า เข้าทำงาน ได้มากกว่าปกติ ถ้าเลือกงานตรงแขนงโหนด, so that ต้นไม้ผูกกับอาชีพ (ข้อ 17)
  6. As a ผู้เล่น, I want โหนดแขนงงานผูกอาชีพที่ทำอยู่ และงานขยับหลอดเฉพาะตอนทุ่มโหนดแขนงงาน, so that ทำงานตรงสายช่วยเฉพาะตอนตั้งใจ (ข้อ 17 26 53)
  7. As a ผู้เล่น, I want อาชีพตรงได้โบนัสชั้นเดียวไม่ว่าทางไหน, so that ผลไม่ซ้อนจนเกินงบ (ข้อ 50 53)
  8. As a ผู้เล่น, I want ผลติดตัวจางถ้าทิ้งนาน (สนิม) และเห็นคำ "เริ่มจาง" บนโหนด โดยตัวเลือกที่ปลดยังอยู่, so that ต้องใช้ของที่ฝึกไว้ (ข้อ 31 63)
  9. As a ผู้เล่น, I want "ใช้" โหนดหมายถึงตอบการ์ดหมวดตรงแขนง ไม่ต้องทุ่ม, so that กันสนิมได้โดยไม่เสียปี (ข้อ 63)

ผู้เล่น · keystone · โหนดซ่อน · ล้าง

  1. As a ผู้เล่น, I want โหนดหักเห (keystone) บางตัวได้แรงแต่เสียถาวร, so that มีทางเลือกเสี่ยงที่เปลี่ยนชีวิต (ข้อ 28)
  2. As a ผู้เล่น, I want keystone ไม่เลื่อนเข้าเอง · ไม่ซ่อน · บอกข้อเสียเป็นคำก่อนทุ่ม · ล้างไม่ได้, so that ไม่เสียถาวรโดยไม่รู้ตัว (ข้อ 60)
  3. As a ผู้เล่น, I want โหนดซ่อนที่เห็นเมื่อเข้าใกล้ โดยจองช่อง "?" ไว้ที่เดิม ต้นไม้ไม่ขยับตำแหน่ง, so that มีของให้ค้นพบโดยภาพไม่กระโดด (ข้อ 29 61)
  4. As a ผู้เล่น, I want ล้างโหนดได้ปีละ 1 โหนด จ่ายด้วยเวลา (keystone ล้างไม่ได้), so that แก้ทางที่เลือกผิดได้แต่มีราคา (ข้อ 34 56)

ผู้เล่น · วัยเด็ก

  1. As a ผู้เล่น, I want นิสัยวัยเด็กเป็นโหนดในต้นไม้ ปลดได้หลายนิสัย ปลดได้ถึงอายุ 12, so that วัยเด็กปูทางต้นไม้ (ข้อ 16 19)
  2. As a ผู้เล่น, I want มีนิสัยเด่นตัวเดียวที่ได้ผลคูณ + ข้อความอายุ 12 ตัวอื่นแค่ปลดตัวเลือก, so that นิสัยไม่ซ้อนผลเกินงบ (ข้อ 51)
  3. As a ผู้เล่น, I want โหนดนิสัยผูกอาชีพที่เข้ากัน, so that นิสัยวัยเด็กมีทางไปถึงงาน (ข้อ 17)
  4. As a ผู้เล่น, I want โหนดเด็กสายธรรม + นิสัยใหม่ 1 ตัว (เช่น ไปวัดกับยาย/เข้าค่ายธรรมะ + นิสัยสงบใจ), so that แขนงความเชื่อ/ธรรมมีทางเข้าตั้งแต่เด็ก (ข้อ 52)

ผู้เล่น · จอ

  1. As a ผู้เล่น, I want ภาพต้นไม้แทนรายการในแท็บโฟกัส, so that เห็นเส้นทาง (ข้อ 12)
  2. As a ผู้เล่น, I want ดูทีละแขนง (แตะชื่อแขนงแล้วเห็นต้นแขนงนั้น พอดีจอ 390) + ต้นเต็มเลื่อน/ซูม, so that ใช้บนมือถือได้และเห็นภาพรวมได้ (ข้อ 47 47ก)
  3. As a ผู้เล่น, I want หลอดไม่มีตัวเลข + คำบอกขั้น (เช่น "รอโอกาส" ตอนปีครบแต่ยังไม่เจอเหตุการณ์), so that รู้ว่าติดอะไรโดยไม่เห็นตัวเลข (ข้อ 10 46)
  4. As a ผู้เล่น, I want หน้าเว็บโฟกัสและส่วนปณิธานเดิมถูกแทนด้วยต้นไม้, so that ไม่มีสองระบบซ้อนบนจอ (ข้อ 47ก)

ผู้เล่น · ข้ามรุ่น · เซฟ · ฉายา

  1. As a ทายาท, I want เกิดตามฐานะ + ได้โหนดแรกฟรี (ไม่ใช่นิสัย) ของแขนงโฟกัสหลักพ่อแม่ + ประตูที่เปิดแล้ว, so that ชีวิตพ่อแม่ส่งต่อแต่ไม่ยกต้นให้ (ข้อ 4 18 38)
  2. As a ทายาท, I want นิสัยคงกติกาครึ่ง heir_nature เดิม, so that กติกานิสัยข้ามรุ่นไม่เปลี่ยน (ข้อ 38)
  3. As a ทายาท, I want โหนดฟรีได้ผลทางที่พ่อแม่เลือก (เซฟเก่า = ทางแรก) และล้างได้ตามกติกาข้อ 56, so that ผลเลือกของพ่อแม่ส่งต่อ (ข้อ 65)
  4. As a ผู้เล่นเซฟเก่า, I want เริ่มต้นไม้ว่าง กลับเป็นตามน้ำ แต่เก็บประตูที่เปิดแล้ว + นิสัย (ปลดโหนดตรงกันให้), so that เซฟเก่าเล่นต่อได้ไม่เสียของสำคัญ (ข้อ 13 48)
  5. As a ผู้เล่น, I want ฉายาตอนตายอ่านแขนงกายใจ + รูปทรงต้น (ลึก/กว้าง) นับโหนดที่เคยปลด (ล้างแล้วยังนับ), so that รูปต้นไม้มีความหมายตอนจบ (ข้อ 30 56 62)

เจ้าของ · ผู้รวมงาน · dev

  1. As a เจ้าของ, I want ใบแรกเป็นเลนร่างต้นไม้ ~40 โหนดเป็นหน้า HTML ให้เคาะ, so that เห็นโหนดทั้งต้นก่อนลงเนื้อ (ข้อ 22)
  2. As a เจ้าของ, I want หน้า tweak 2–3 แบบของจอต้นไม้ก่อนลงจริง, so that เลือกจอเองตามกฎหน้า tweak (ข้อ 12 47ก · INTEGRATOR.md)
  3. As a เจ้าของ, I want ความแรงผลติดตัวทำตามดีไซน์ก่อน แล้วยื่นด่านที่ตกให้เคาะทีละด่าน, so that ตัดสินตัวเลขจากผลวัด (ข้อ 11)
  4. As a เจ้าของ, I want งบผลติดตัวทั้งต้นรวมไม่เกินผลโฟกัสเดิมหนึ่งตัว ตั้งในสเปกก่อนแล้วค่อยวัด, so that ต้นไม้ไม่ทำเกมง่ายขึ้นเงียบ (ข้อ 42)
  5. As a เจ้าของ, I want ช่องใหม่ 24–35 (ตัวเร่ง · ทอย · keystone · เลือกผล) "ไม่จำกัด วัดแล้วตัด", so that ลองของใหม่ก่อนแล้วค่อยตัด (ข้อ 55)
  6. As a เจ้าของ, I want ต้นทุนของข้อที่ยืนทางที่ผู้ค้านค้าน (36 41 49 57 58) เป็นเกณฑ์วัด, so that รู้ว่าจ่ายไปเท่าไร (ข้อ 36 41 49 57 58)
  7. As a ผู้รวมงาน, I want engine เขียนให้เสียบต่างโลก/ปรโลกต่อได้ภายหลัง, so that grill แยกรอบหน้าไม่ต้องรื้อ (ข้อ 2 40)
  8. As a dev, I want lint ตรวจกติการ่างต้นไม้ (ทุกวัย ≥1 โหนดต่อแขนง นับเฉพาะโหนดที่เห็น · FOCUS_GROUPS รับแขนงธรรม), so that เนื้อผิดกติกาตกก่อน merge (ข้อ 44 52 61)
  9. As a dev, I want บอทเล่นต้นไม้ (เลือกผลด้วย rng แยกแบบ botFocus), so that harness วัดฉายา/งบได้ (ข้อ 62 64)

Implementation Decisions

ขอบเขตโลก

  • กติกากลางทุกโลก ลงเนื้อโลกหลักก่อน (ข้อ 2) → ทับโดยข้อ 40: ต้นไม้เฉพาะโลกหลักก่อน — ต่างโลก/ปรโลกเดินแบบเดิม ไว้ grill แยก · engine เขียนให้เสียบต่อได้ภายหลัง

ของเดิม

  • ของเดิม (21 โฟกัส · สายต่อ 9 คู่ · ประตู 5 สาย): ออกแบบโหนดใหม่ทั้งหมด (ข้อ 3) · ใหม่หมดทั้งชื่อ (ข้อ 41)
  • ประตู 5 สาย: กระจายไปปลายแขนงที่เกี่ยว + บางแขนงกลับมาบรรจบกันได้ (ข้อ 21) → ทับบางส่วนโดยข้อ 37: ประตูอยู่ลึก 2–3 โหนด — ปลายแขนงเป็นโหนดต่อยอด/keystone · ทางบรรจบยังมี

โหนดและโครง

  • โหนดในต้นไม้ = ผสม: ทุ่มทีละตัว + ปลดโหนดติดตัว · "1+โหนดติดตัว ทำใหม่มีตัวเลือกสำหรับทุกเทสายนั้นๆเพืิ่ม" (ข้อ 1)
  • รูปทรง: ต้นเดียวทั้งชีวิต 5 แขนง (ข้อ 76 ทับข้อ 6 23) · แขนง: เงิน · ความสัมพันธ์ · ความรู้ · ทักษะ · ลึกลับ (ข้อ 76 81)
    • เงิน → โหนดกลางพาไปงาน · สายมืด · ความสัมพันธ์ → โหนดกลางพาไปครอบครัว · สังคม/เพื่อน · การเมือง (ข้อ 77 · โหนดกลาง "และ" คู่แขนงเลน A เสนอ · ทุกคู่ = 10 คู่ ข้อ 71)
    • ความรู้มีผลต่องาน: สอบเข้า/ได้งานง่ายขึ้น · เร่งปลดโหนดสายงาน · เปิดอาชีพสายวิชาชีพ · โหนดกลางความรู้+งาน (ข้อ 79)
    • ทักษะ = กายใจเดิม (รวมส่วนใจ) ผลเน้นอายุยืน เล่นได้นานขึ้น (ข้อ 76 78 81)
    • ลึกลับ = สายความเชื่อเดิม · ผลมากในโลกซ้อนทับ จดไว้ลงทีหลังตามข้อ 40 (ข้อ 80)
    • ประตูเดิม: business/shortcut_money → เงิน · politics_base → ความสัมพันธ์ · ordain/occult → ลึกลับ
  • ขนาดโลกหลัก ~40 โหนด (แขนงละ ~10) (ข้อ 14) · 40 ตั้งแต่แรก (ข้อ 49) · บวกโหนดกลางระหว่างแขนง เกิน 40 ได้ (ข้อ 69)
  • ทางแยก: ไม่ล็อก เวลาเป็นราคา (ข้อ 8)
  • ทุกวัยต้องมีโหนดให้ทุ่ม ≥1 ต่อแขนง — กติการ่างต้นไม้ + lint ตรวจ (ข้อ 44) · lint นับเฉพาะโหนดที่เห็น (ข้อ 61)
  • ใครร่างโหนด ~40: ใบแรก = เลนร่างต้นไม้เป็นหน้า HTML ให้เจ้าของเคาะ (ข้อ 22)

จุดเริ่ม

  • เกิดที่ต้นแขนงตามฐานะ/ครอบครัว (ข้อ 15) · เริ่มได้แขนงเดียว ลำดับ ฐานะ > อาชีพ > แขนงพ่อแม่ (ข้อ 39) · จุดเกิดดูอาชีพพ่อแม่ด้วย (ข้อ 17)

ราคาและการปลด

  • ราคาปลด: ปีเต็ม + ต้องผ่านเหตุการณ์ · "3+ แต่ลโหนดมีแต้มในการปลดโหนดถัดไป ไม่เท่ากัน" (ข้อ 7)
  • 'ผ่านเหตุการณ์' ผสมตามขนาดโหนด: โหนดเล็ก = กดตัวเลือกตรงสายบนการ์ดทั่วไปครบจำนวน · โหนดใหญ่ ปลายแขนง/ประตู = การ์ดด่านของตัวเอง 1 ใบโผล่เมื่อปีครบ (ข้อ 9) → โหนดเล็กทับโดยข้อ 45: นับตามหมวดการ์ด — ตอบการ์ดหมวดตรงแขนงข้อไหนก็นับ ไม่ติดป้ายรายตัวเลือก
  • ทุ่มโหนดที่กำลังจะปลด (ปีเต็มเข้าหลอดโหนดนั้น · ระหว่างทุ่มได้ผลรายปีเต็มของโหนด · ปลดแล้วเหลือผลเบาถาวร) (ข้อ 20) · ทุ่มได้แค่โหนดที่ยังไม่ปลด (ข้อ 36)
  • ปลดแล้วเลื่อนไปโหนดถัดไปเอง ไม่เสียปี — ผู้เล่นเปลี่ยนเองทีหลังได้ (เปลี่ยนแบบนี้ไม่เสียปี) (ข้อ 43) · ไม่เลื่อนเข้า keystone เอง (ข้อ 60)
  • ตัวเร่ง/ชะลอการปลด (ครู · ฐานะ · นิสัยใฝ่รู้ · ยิ่งแก่ยิ่งช้า แบบสูตรเรียนวิชาอสงไขย) (ข้อ 24) · คงครบตามเดิมแล้ววัด (ข้อ 57) · สูตร ×0.6 อสงไขยต้องย่อสเกลอายุไทย ~75
  • ทำงานแล้วโหนดงานขยับเอง (ข้อ 26) → ทับโดยข้อ 53: งานขยับหลอดเฉพาะตอนทุ่มโหนดแขนงงาน — นับเป็นโบนัสชั้นเดียวกับข้อ 50 · ยึดข้อ 20/36 ทุ่มทีละโหนด
  • ตาเลือกครู/ที่ปรึกษาช่วงวัยเรียน (ข้อ 27) → ทับโดยข้อ 59: ตัวเลือกครู/ที่ปรึกษาฝากไว้ในด่านจบประถม — ไม่เพิ่มการ์ด ไม่แตะโควตา · คนไม่ได้เรียนไม่เจอ

ผลติดตัว

  • โหนดที่ติดตัวให้: ตัวเลือกใหม่บนการ์ดเดิม · การ์ดหมวดนั้นออกบ่อยขึ้นถาวร · ผลรายปีเบาถาวร (ข้อ 5)
  • ความแรง: ทำตามดีไซน์ก่อน แล้วยื่นด่านที่ตกให้เคาะทีละด่าน (ข้อ 11) → ทับโดยข้อ 42: ตั้งงบผลในสเปกก่อน — ผลติดตัวทั้งต้นรวมไม่เกินผลโฟกัสเดิมหนึ่งตัว · ถ่วงการ์ดถาวรเฉพาะแขนงที่ปลดมากสุด · แล้วค่อยวัด
  • งบ: "ไม่จำกัด วัดแล้วตัด" ใช้เฉพาะช่องใหม่ 24–35 (ตัวเร่ง · ทอย · keystone · เลือกผล) — ผลติดตัวคงงบข้อ 42 (ข้อ 55)
  • ทอยโอกาสตามโหนดบนตัวเลือกเดิม (ข้อ 25) → ข้อ 58: ทอยทุกโหนด ตามหมวดการ์ด (คิดรวมต่อแขนง · ข้อ 45) ใช้กลไกเดิมแบบตัวคูณสกิลต่างโลก · ซ้อนสกิลต่างโลก/สัญญามารชนเพดาน okMax 0.95 · ป้ายบนปุ่มยังเป็น "สำเร็จ ~X%" เดิม ไม่ทำป้าย "ใช้<วิชา>" ใหม่
  • ผูกอาชีพ (ข้อ 17 ติ๊ก 4): จุดเกิดดูอาชีพพ่อแม่ด้วย · โหนดนิสัยผูกอาชีพที่เข้ากัน · โหนดแขนงงานผูกอาชีพที่ทำอยู่ · "มีโอกาสทำงาน สอบเข้า เข้าทำงาน ได้มากกว่าปกติ ถ้าเลือกงานตรงแขนงโหนด" → ข้อ 50: ครบ 4 แต่ไม่ซ้อน — อาชีพตรงได้โบนัสชั้นเดียวไม่ว่าทางไหน · อยู่ในงบผลข้อ 42
  • สนิม: ผลติดตัวจางถ้าทิ้งนาน — ผลรายปีเบาจาง · ตัวเลือกที่ปลดยังอยู่ · ยังไม่มีกลไกในโค้ด ต้องสร้าง (ข้อ 31) · "ใช้" = ตอบการ์ดหมวดตรงแขนง (ข้อ 45) ไม่ต้องทุ่ม · บอกคำ "เริ่มจาง" บนโหนด · ลอกแบบการจางของโรคเรื้อรังที่มีอยู่ (ข้อ 63)

  • ช่องฝังของ (ข้อ 33) → ข้อ 54: เลื่อนไปทำหลังมีตลาด (ใบ 04b) — สเปกต้นไม้รอบนี้ไม่มีช่องฝัง
