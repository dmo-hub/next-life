ข้อมูลอ้างอิง (lore)

ข้อมูลที่ใช้ตอนเขียนเนื้อหาและตัวเลข แหล่งที่มาอยู่ในแต่ละไฟล์ · เวอร์ชัน v0.6.89

มีเฉลยสำเนาอ่านอย่างเดียวเอกสารชุดนี้เปิดกลไกที่ในเกมซ่อนไว้ คัดจาก design/ ของ repo แก้บนหน้านี้ไม่ได้

ในหน้านี้

  1. แผ่นคติสำหรับเกม: ช่วงระหว่างชาติ (คติไทย)
  2. REF สาเหตุการตาย (B110) — ที่มาของ `data/death-causes.json`
  3. แผ่นข้อมูลตามยุค: เกมจำลองชีวิตคนไทย (เกิด พ.ศ. 2500–2569)
  4. แผ่นข้อมูลออกแบบเกมจำลองชีวิตคนไทย: การเงิน, ความเชื่อ, เรื่องเล่าพื้นบ้าน
  5. lore-isekai-balance: อายุตายคาด + สมดุลสกิล 3 ทาง
  6. ต่างโลก: ไอเทมและสกิล (ข้อมูลประกอบ popup)
  7. lore-isekai-knowledge: ความรู้โลกเดิมในต่างโลก + ตัวเลือก popup
  8. lore-isekai-media: มังฮวา เกม อนิเมะ/มังงะเพิ่มเติม + ความนิยมในไทย (ข้อมูลประกอบ popup)
  9. lore-isekai-merit: หมวดบุญบาปต่างโลก + น้ำหนัก (ข้อเสนอให้เจ้าของเคาะ)
  10. lore-isekai-money: เงินต่างโลก + มรดกเมื่อกลับโลกเดิม
  11. lore-isekai-quest-status-guild: เควส · หน้าต่างสถานะ · กิลด์ในต่างโลก + ตัวเลือก popup
  12. lore-isekai-setting: เซ็ตติ้งโลกต่างโลก + ตัวเลือก popup
  13. lore-isekai: ข้อมูลต่างโลกเพื่อทำ popup ประกอบการตัดสินใจ

1. ยมโลกและการตัดสิน

  • เมืองพญายมราชใหญ่และอ้อมรอบประตูนรกทั้ง 4 พญายม "ทรงธรรมนักหนาพิจารณาถ้อยความ" [พุทธ] https://th.wikisource.org/wiki/ไตรภูมิพระร่วง/นรกภูมิ
  • เทวดา 4 องค์ถือบัญชีบุญและบาป แล้ว "ชักบุยและบาปนั้นมาดูทั้งสองฝ่าย ๆ ใดหนักก็ไปฝ่ายนั้น" ผู้ที่บุญหนักกว่าอาจต้องกลับมารับผลบาปที่เหลือภายหลัง ผลตัดสินจึงมีหลายระดับได้ [พุทธ] (URL เดียวกัน)
  • ยมบาลทำตามคำบังคับ พาไป "โดยบาปกรรมมันอันหนาและเบา" หน้านรกภูมิใช้คำ "ยมบาล" ตลอด ไม่พบคำ "นิรยบาล" (ข้อสรุปนี้ใช้กับหน้านี้หน้าเดียว) [พุทธ] (URL เดียวกัน)
  • เทวทูตสูตร (MN 130): พญายมซักถามและตำหนิผู้ประมาทว่าเห็นเทวทูต 5 หรือไม่ ได้แก่ ทารก คนชรา คนป่วย กษัตริย์ลงโทษโจร และศพ ทั้งหมดเป็นภาพในโลกมนุษย์ ยมตรัส "That evil kamma was done by you yourself" ในพระสูตรไม่มีบัญชีหรือตาชั่ง [พุทธ] https://www.accesstoinsight.org/tipitaka/mn/mn.130.than.html
  • ทุกข์ในนรกไม่ถาวร เมื่อกรรมหมดก็ตายไปเกิดตามกรรมที่เหลือ (ผู้แปล Note 6) ไตรภูมิก็ว่า "สิ้นกรรมนั้น…ตายไปเกิดเป็นแห่งอื่น" แต่อเวจีกินเวลา 1 กัป [พุทธ] (2 URL ข้างบน)
  • ยมบาล/นิรยบาลคือเจ้าพนักงานที่ลงโทษตามคำสั่งพระยม (หน้าอ้างพจนานุกรมราชบัณฑิตยสถาน 2554 หน้า 939) ยมทูตแค่นำและควบคุมวิญญาณ ไม่ลงโทษ บทบาทยมทูตแบบนี้เป็นคติพุทธ ฝ่ายฮินดูให้ยมทูตลงโทษด้วย [ผสม] https://th.wikipedia.org/wiki/พระยม
  • ยมเป็นผู้ตัดสินคนตาย มีภาพฉากศาลยมที่วัดม่วง (ใช้อ้างอิงงานภาพ) [ผสม] https://en.wikipedia.org/wiki/Yama_(Buddhism)
  • พระมาลัยลงไปนรก และถูกขอให้ญาติที่ยังมีชีวิต "make merit on their behalf" เป็นวรรณกรรมพุทธพื้นบ้าน อยู่นอกพระไตรปิฎก [พุทธ] https://en.wikipedia.org/wiki/Phra_Malai
  • (ยังไม่แน่น) ผู้จดบัญชี: จิตรคุปต์ (คติฮินดู) และพระสุวรรณเลขาจดบุญในบัญชีแผ่นทองสุก (คติไทย) หน้าไม่มีแหล่งอ้างอิงกำกับ [ผสม] https://th.wikipedia.org/wiki/พระยม

  • C. สุ่มให้ ข้อดี: ไม่ต้องคิด · ข้อเสีย: ผู้เล่นไม่มีส่วนร่วม

  • B. กรรมปลดล็อกสกิลต้องสาป/พิเศษ (แบบ Shield Hero) ข้อดี: ผูกกับบัญชีบุญบาป · ข้อเสีย: ผู้เล่นไม่รู้ล่วงหน้า (บัญชีซ่อน)
  • C. ทั้งสองทาง ข้อดี: เนื้อหาหลากหลาย · ข้อเสีย: งานเยอะ
  • แนะนำ C แต่ส่งมอบ A ก่อน แล้วเติม B ในรอบถัดไป เหตุผล: A ไม่แตะ afterlife.mjs ที่หลายเลนใช้ร่วม

  • B. ไม่ส่งอะไร ข้อดี: เรียบ · ข้อเสีย: เสียเสน่ห์ชีวิตต่อเนื่อง
  • C. ส่งสกิลทั้งหมด ข้อดี: ผู้เล่นสะใจ · ข้อเสีย: โกงเร็วเกินไป ชาติหลังไม่มีอะไรให้เลือก
  • แนะนำ A เหตุผล: ไม่พบตัวอย่างเรื่องไหนที่ส่งไอเทมข้ามชาติ จึงออกแบบเองให้เล็กและควบคุมได้

  • B. ไม่ใส่ ข้อดี: ไม่เสี่ยง · ข้อเสีย: ไม่ต่างจากเกมต่างโลกทั่วไป
  • C. แยกเป็น "ของจากโลกเดิม" ที่เอาติดตัวมาจากชาติไทยได้ ข้อดี: ผูกกับชาติไทยในเกมเดียวกัน ตรงธีมจำเหตุการณ์ข้ามชาติ · ข้อเสีย: ต้องแตะระบบชาติไทย (ชนเลนอื่น)

3. กลไกเกม [ความเห็น] ทั้งหมด (ไม่มีแหล่งภายนอกสำหรับ "เกมนี้ควรทำอย่างไร")

  • ค่า "รู้" ถึงเกณฑ์: ควร ใช้เกณฑ์ต่อมุก (เช่น รู้ ≥ N + ช่วงวัย) เพราะต้นแบบมีค่ารู้อยู่แล้ว · ต่ำกว่าเกณฑ์ = ทำไม่ได้ ไม่ใช่ล้มเหลว
  • ช่วงวัย: เด็กเล็กทำไม่ได้ (ไมน์เป็นเด็กแต่ต้องมีผู้ใหญ่/พ่อค้า) → ปลดล็อกวัยรุ่นขึ้นไป หรือเด็กทำได้ถ้ามี "ผู้สนับสนุน" (สัมพันธ์สูง)
  • โอกาสล้มเหลว: ควรมี · ตามเรื่องจริงล้มก่อนสำเร็จ (พิมพ์บล็อกไม้ล้ม) · ล้มครั้งแรกเก็บ "ความคืบหน้า" ไว้ ลองใหม่ได้
  • ผลต่อโลกถาวร: ทำได้ตรงกับโลกจำข้ามชาติ · เก็บเป็นธงในโลก ("มีมายองเนสในเมือง") แสดงในจดหมายเหตุ/หน้าแรกชาติถัดไป
  • บุญบาป: ควรลงบัญชี · มุกกระทบคนได้สองทาง (ค่ายา/อาหารช่วยคน = บุญ · ทำคนตกงาน/ผูกขาดราคา/อาวุธ = บาป) ใช้หมวดบัญชีต่างโลกที่ MAP ตัดสินแล้ว

4. ข้อควรระวัง [ความเห็น]

  • ดินปืน/ยาพิษ/อาวุธ: ห้ามให้ขั้นตอน/สูตรในเกม · เขียนเป็นผล ("ได้อาวุธใหม่ เมืองเปลี่ยน") ไม่ใช่วิธีทำ · ผูกกับบาปและช่วงวัยผู้ใหญ่
  • ยา/สมุนไพร: ห้ามอ้างรักษาโรค · ใช้ "บรรเทาปวดเมื่อย" ตามหลักฐานเรื่องความร้อน
  • หวย/พนัน: ไม่ทำเป็นกลยุทธ์ที่เห็นผลชนะ
  • ประวัติมวยไทย/พระเครื่อง: เขียนเป็น "ตำนาน/ความเชื่อ" เพราะหลักฐานเถียงกัน
  • ใช้ปัญหาข้อความผู้เล่นเห็นกับ humanizer ตาม MAP

  • แนะนำ ค) เพราะเรื่องจริงล้มก่อนสำเร็จ · ธงน้อย ๆ ไม่ล้นเซฟ

  • ค) มีโอกาสล้ม + ผลบุญบาปสองทาง · เสีย: ต้องตั้งค่าเยอะ

พาเงิน/ของข้ามโลก

  • ชาติไทย → ต่างโลก: ไม่พาเงิน (ตรงกับเกิดใหม่ตัวเปล่าที่เป็นแบบสามัญ) · ของที่ติดตัวมีได้ใน 2 ทางเข้าแบบไม่ตาย (วงเวท/ประตู/เกม) เป็นไอเทมตามช่องที่เคาะ ไม่ใช่เงิน [Decisions: ช่องไอเทม 4]
  • ต่างโลก → ต่างโลกถัดไป: ไอเทม 1 ชิ้นที่เลือกเอง (เคาะแล้ว) + ทองเป็น % ตามสายเลือด/ศิษย์ แบบอสงไขย (50%/20%) หรือไม่ส่งทองเลย แบบ Rogue Legacy ที่บังคับแปลงเป็นของถาวร

4. กลไกที่เข้ากับเกมนี้ [ความเห็น ทั้งหมด]

  1. เควส = บอร์ดให้เลือกทุ่มเททุกช่วงวัย: เควสเป็น 1 ใน ตัวเลือก "ทุ่มเท" ของ 1 ช่วงวัย (ปราบ/ส่งของ/คุ้มกัน/สืบ) แทนการสุ่มเหตุการณ์ · งานที่จ่ายน้อยแต่เลื่อนขั้นช้า (มุกงานก็อบลิน) ใช้ทำ trade-off เงิน vs แรงค์ได้จริง
  2. แรงค์กิลด์เป็นเป้าหมายชีวิต: เข้ากับ "เลือกสิ่งที่จะทุ่มเททุกช่วงวัย" และตายก่อนถึงขั้นสูงได้ · แรงค์สูงสุดที่ยังออกภาคสนามต่ำกว่าสุดยอด (Silver ใน Goblin Slayer [บล็อก]) เป็นเพดานให้ทำ "จบแบบสบาย vs ไต่ต่อ" ได้
  3. หน้าต่างสถานะเป็น UI หลักโหมดต่างโลก: แสดงชื่อ เผ่า เลเวล HP/พลัง/เวท/เสน่ห์/โชค สกิล ช่องไอเทม 4 ช่อง ฉายา แรงค์กิลด์ ชื่อเสียง · ชาติไทยเป็นการ์ดทีละใบ ต่างโลกเป็นหน้าจอข้อมูลที่เปิดตลอด ⇒ "แนวเกมเปลี่ยนชัดเจน"
  4. ใครเห็นสถานะ: เริ่มด้วย "เห็นเฉพาะของตัวเอง" แล้วให้เควส/สกิลประเมินปลดล็อกการเห็นของคนอื่นเป็นของรางวัล (ตามกลไก Appraisal ของ Spider [อ่านจากแหล่ง ข้อ 3])
  5. ฉายาจากการกระทำ ต่อกับระบบฉายาเดิม: ฉายาต่างโลกตามฉายา 28 ตัวของเกมหลัก เช่น Death March "god slayer" / Spider "Hero" (ถูกมอบตามเหตุการณ์) · ลวดลาย "ชีวิตแบบ…" ใช้เป็นหัวชาติต่างโลกได้ ถ้าจะสืบทอดข้ามชาติ = ผูกกับ "ตำนานที่โลกจำ" ที่เจ้าของตัดสินแล้ว
  6. เควสผูกบุญบาป/ชื่อเสียง: เควสเดียวลงได้ทั้งสองฝั่ง เช่น ปราบเผ่าที่เป็นภัยจริง vs ล่าเผ่าที่ไม่มีภัย · ชื่อเสียงแยกแกน เปิดเควสแรงค์สูงและราคา · ต่อกับ "ตำนานเสีย" แบบ Shield Hero (ถูกจำเป็นคนร้าย) แต่ไม่ใช้ฉากล่วงละเมิด

5. ข้อควรระวังเกมทุกวัย [ความเห็น · บางข้อมีข้อเท็จจริงประกอบ]
