ห้องผู้พัฒนา

เครื่องมือ แผนที่ แผนงาน และต้นแบบ สำหรับคนที่ร่วมทำเกม · ผู้เล่นไม่ต้องอ่านก็เล่นได้

ร่วมพัฒนา

  • repo บน GitHubอ่าน CONTRIBUTING.md ก่อนส่งงาน · ส่งงานเป็น PR ตัวตรวจอัตโนมัติรันให้ทุกครั้ง
  • ด่านก่อนส่งงานnpm run lint:test · npm run harness:test · npm run site:check · npm run check:data · แก้เนื้อการ์ดแล้ว npm run build ก่อน commit
  • ปล่อยรุ่นใหม่npm run rel -- <notes.json> เขียนแพตช์โน้ต bump เลข และ commit · หัว "กำลังทำ" ในแพตช์โน้ตแก้มือในหมวดที่ตรง

ออกแบบเกม

  • เอกสารออกแบบเกม (GDD.md)ไฟล์ GDD.md ในรากของ repo · ภาพรวม แก่น วงจร ลูป เทคนิค ขอบเขต · กติกาแต่ละระบบย้ายไปหน้ากลไกในเกม/ปรโลก/ต่างโลก
  • ภาคผนวกสเปกและรีเสิร์ชเอกสาร docs/spec ทุกไฟล์ในหน้าเดียว
  • คำตัดสินเกมแผนที่และคำตัดสินของเจ้าของแยกตามเรื่อง
  • การออกแบบดีไซน์ UI: สี ตัวอักษร ชิ้นส่วนหน้าเล่น คำตัดสิน UI และหน้า tweak
  • ระบบที่กำลังทำหัว "กำลังทำ" ในแพตช์โน้ต แบ่งตามหมวด

สเปกและแผน

  • แผนเฟส + แกนต่อเนื่องลำดับเฟสและด่านของแต่ละเฟส
  • ข้อมูลการเงินในเกมชุดตัวเลขหุ้น ทอง ดอกเบี้ย บ้าน พร้อมที่มา

แผนที่

  • ทวีป · ปรโลก · ดันเจียน
  • ตระกูล · หลักไมล์ · การเมืองวาดด้วย canvas ล้วน 6 แท็บ

ต้นแบบหน้าเล่นใหม่

  • ปรับหน้าเล่นสดจอต้นแบบกดได้ ปรับเลย์เอาต์/ชิ้นย่อยสด · เริ่มจาก A/B/C · ตารางเทียบ 3 สไตล์ · คัดลอกคำตอบ
  • B67 สถิติวิญญาณ + จอนิพพาน/โพธิสัตว์แท็บที่ 4 ในชั้นสมุด · จอถึงเกณฑ์บารมีข้ามชาติ · preset A/B/C · คัดลอกค่า
  • ปุ่มแท็บชั้นสมุด 5 แบบเดิม · สันหนังสือ · ขีดเส้นใต้ · กล่องเหลี่ยม · ป้ายคั่นหน้า · 6 แท็บ grid3 · 360/390/1280 สองธีม · วัด contrast ในหน้า · ใช้ CSS เกมจริง · คัดลอก JSON
  • เอฟเฟกต์ได้ฉายา: หายาก vs ตำนานดีไซน์ใหม่ 3 แบบวางคู่หายาก/ตำนาน · หยุดภาพทีละจังหวะ/เฟรมสุดท้าย · ขาวดำ · 390/1280 · คัดลอก JSON
  • ใบชวนไปต่างโลกใบชวน + ใบลางเป็นการ์ดธรรมดา · ถามซ้ำแบบเบา · ใช้ CSS เกมจริง · เริ่มจาก ก/ข/ค · คัดลอกคำตอบ
  • หัวการ์ด + เมนู 6 ปุ่ม + แท็บโฟกัสเกจฐานะ 10 ขั้น · เงินสดย่อคำไทย · แถวอาชีพ · เมนู 6 ปุ่ม 3 แบบ · แท็บโฟกัส 3 แบบ · จอ 360/390/1280 ใน iframe ใช้ CSS เกมจริง · คัดลอก JSON
  • ป้ายผลบนปุ่มเป็นไอคอนไอคอน/อิโมจิ + สีขึ้นลงแทนคำ · ไทย + ต่างโลก · ค่าซ่อนยังซ่อน · โหมดขาวดำ · ใช้ CSS เกมจริง · เริ่มจาก ก/ข/ค · คัดลอกคำตอบ
  • การ์ดตาย / หน้าไว้อาลัยแบบใหม่ 3 แบบเทียบแบบปัจจุบัน · ชีวิตจริง 6 แบบ (เด็กตาย · คนแก่รวย · ฉายาเยอะ · หลอดหมด · หนี้ · หายตัว) · ข้อมูลเดิมครบ · แท็บ 6 ตัวชื่อเดิม · คัดลอก JSON
