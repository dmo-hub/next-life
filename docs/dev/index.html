ห้องผู้พัฒนา

เครื่องมือ แผนที่ แผนงาน และต้นแบบ สำหรับคนที่ร่วมทำเกม · ผู้เล่นไม่ต้องอ่านก็เล่นได้

ร่วมพัฒนา

  • repo บน GitHubอ่าน CONTRIBUTING.md ก่อนส่งงาน · ส่งงานเป็น PR ตัวตรวจอัตโนมัติรันให้ทุกครั้ง
  • ด่านก่อนส่งงานnpm run lint:test · npm run harness:test · npm run site:check · npm run check:data · แก้เนื้อการ์ดแล้ว npm run build ก่อน commit
  • ปล่อยรุ่นใหม่npm run rel -- <notes.json> เขียนแพตช์โน้ต bump เลข และ commit · หัว "กำลังทำ" ในแพตช์โน้ตแก้มือในหมวดที่ตรง

ออกแบบเกม

  • เอกสารออกแบบเกม (GDD.md)ไฟล์ GDD.md ในรากของ repo · ภาพรวม แก่น วงจร ลูป เทคนิค ขอบเขต · กติกาแต่ละระบบย้ายไปหน้ากลไกในเกม/ปรโลก/ต่างโลก
  • ภาคผนวกสเปกและรีเสิร์ชเอกสาร docs/spec ทุกไฟล์ในหน้าเดียว
  • คำตัดสินเกมแผนที่และคำตัดสินของเจ้าของแยกตามเรื่อง
  • การออกแบบดีไซน์ UI: สี ตัวอักษร ชิ้นส่วนหน้าเล่น คำตัดสิน UI และหน้า tweak
  • ระบบที่กำลังทำหัว "กำลังทำ" ในแพตช์โน้ต แบ่งตามหมวด

สเปกและแผน

  • แผนเฟส + แกนต่อเนื่องลำดับเฟสและด่านของแต่ละเฟส
  • ข้อมูลการเงินในเกมชุดตัวเลขหุ้น ทอง ดอกเบี้ย บ้าน พร้อมที่มา

แผนที่

  • ทวีป · ปรโลก · ดันเจียน
  • ตระกูล · หลักไมล์ · การเมืองหน้าเดียวสลับ 6 ผัง · วาดด้วย canvas ล้วน
