เอกสารผู้พัฒนา

สเปก แผนที่ งานศึกษา และต้นแบบเก่า · ผู้เล่นไม่ต้องอ่านก็เล่นได้

ออกแบบเกม

  • เอกสารออกแบบเกม (GDD)กติกาทุกระบบ + ภาคผนวกสเปกจาก docs/spec

สเปกและแผน

  • แผนเฟส + แกนต่อเนื่องลำดับเฟสและด่านของแต่ละเฟส
  • ข้อมูลการเงินในเกมชุดตัวเลขหุ้น ทอง ดอกเบี้ย บ้าน พร้อมที่มา

แผนที่

  • ทวีป · ปรโลก · ดันเจียน
  • ตระกูล · หลักไมล์ · การเมืองวาดด้วย canvas ล้วน 6 แท็บ

งานศึกษา

  • ศึกษาเกมอื่นสรุปไอเดียจากเกมเว็บที่เล่นแล้ว
  • ศึกษาหนึ่งในอสงไขย

คลังต้นแบบเก่า

  • สารบัญคลังต้นแบบที่ไม่ได้ใช้แล้ว เก็บไว้ดูที่มา

ที่วางของใหม่

HTML ใหม่ของเลนวางใต้ dev/ แล้วเติมในผังเมนู (src/site/nav.mjs) กับกล่องในหน้านี้ · site:check ตรวจว่าไม่มีหน้าตกผัง
