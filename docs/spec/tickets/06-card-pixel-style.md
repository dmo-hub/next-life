## Question

การ์ดแจ้งเกิด · การ์ดตัดสินใจ · การ์ดบันทึกการตาย · ฉากยมโลก ควรหน้าตาแบบไหน ใช้ฟอนต์ไทยอะไร มีพิกเซลตรงไหนบ้าง · ทำ mockup HTML หยาบ ๆ ให้เจ้าของดูแล้วเลือก

## Answer

ต้นแบบ: `../proto/cards-v1.html` (2 แนว × การ์ดตัดสินใจ + ศาลพญายม + ตัวอย่างการสลับ) · เจ้าของเลือก 2026-10-22: **ผสม สลับตามประเภทเหตุการณ์**
- **ทาง A ทะเบียนราษฎร์** (กระดาษ #F4EFE3 · หมึก #1F2430 · ตราแดง #A23B2C · เขียว #2F6B66 · Pridi + Sarabun) = เหตุการณ์ชีวิตจริง: เรียน · งาน · เงิน · ครอบครัว · สุขภาพ · บ้านเมือง
- **ทาง B ลายรดน้ำ** (รักดำ #17110D · ทอง #D9B45A/#F0D78C · Srisakdi + Sarabun) = เหตุการณ์ความเชื่อ/แฟนตาซี: ผี · เจ้าที่ · ขอหวย/บนบาน · ดูดวง · ทำบุญ + ทุกฉากช่วงระหว่างชาติ
- ตัดสินแนวตาม**ประเภทเหตุการณ์** ไม่ใช่ตามตัวเลือก (เกณฑ์ทหารใช้ A แม้มีตัวเลือกไหว้แม่นาค) → ข้อมูลเหตุการณ์ต้องมีฟิลด์ประเภท (ส่งต่อใบ "รูปแบบข้อมูลเหตุการณ์")
- ภาพพิกเซล: SVG ใช้ `shape-rendering: crispEdges` ฉากกว้าง 76×30 หน่วย วางเหนือเนื้อหา · ห้ามวาดพระพุทธรูปหรือพระสงฆ์ (ข้อห้ามจากใบคติไทย)
- ค่าสถานะแสดงเป็นแถบไม่มีตัวเลข · ผลของตัวเลือกบอกแค่ ↑/↓ หรือ ?
- ยังไม่ได้ตัดสิน: การเปลี่ยนแนวระหว่างการ์ดจะมี animation ไหม · การ์ดแจ้งเกิด/บันทึกการตาย (ใช้ A ตามกติกา ยังไม่ได้วาด)
