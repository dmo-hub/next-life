## Question

เหตุการณ์หนึ่งเก็บเป็นข้อมูลรูปแบบไหน (เงื่อนไขเกิด · ตัวเลือก · ผล · ข้อความ) · AI ร่างทีละชุดแล้วเจ้าของตรวจอะไร · harness จำลองชีวิตแบบตั้ง seed ได้ ใช้วัดอะไรบ้างก่อนยอมรับเนื้อหาชุดใหม่ (อายุเฉลี่ย · อัตราฉายา · ตัวเลือกที่ไม่มีใครเลือก)

## Answer

grilling 2026-10-22 (4 รอบ + ตรวจทานเปิดกลับ 4 ข้อ) — ตัดสินโดยเจ้าของ (ทุกข้อตามที่แนะนำ):

### รูปแบบข้อมูลเหตุการณ์
- **ไฟล์**: YAML แยกไฟล์ตามช่วงวัย → สคริปต์ build ตรวจ schema แล้วรวมเป็น JSON ฝังใน HTML ไฟล์เดียว
- **ฟิลด์บังคับ**: id คงที่ · ประเภท (ชี้แนวการ์ด A ทะเบียนราษฎร์ / B ลายรดน้ำ ตามใบ 06) · ช่วงวัย · ช่วงปีที่เกิดได้
- **เงื่อนไขเกิด = ฟิลด์ประกาศล้วน ไม่มีช่อง JS**: อายุ · ปี · ฐานะ · ภาค · เพศ · ค่าสถานะต่ำสุด/สูงสุด · ธง · **สมาชิกครอบครัว** (พ่อแม่/คู่/ลูก เก็บอายุ · ยังมีชีวิต · สุขภาพ · ความสัมพันธ์ — เช่น "มีลูกอายุ 17–19") · harness วิเคราะห์ล่วงหน้าได้ว่าเหตุการณ์ไหนไม่มีทางเกิด
- **โอกาสเกิดในกองสุ่ม**: น้ำหนักฐาน × ตัวคูณตามเงื่อนไข (ฐานะ · ค่าสถานะ · กรรม · ชื่อเสียงตระกูล) · เงื่อนไขแข็ง (อายุ/ปี/ธง) แยกจากตัวคูณ
- **ผลต่อค่าสถานะ**: ระดับ ±1/±2/±3 → ตารางกลางแปลงเป็นตัวเลข (harness ปรับสมดุลทั้งเกมที่จุดเดียว)
- **เงิน 2 หน่วย**: (1) เท่าของรายได้ — ค่าใช้จ่ายตามฐานะ (งานแต่ง · เที่ยว) (2) ราคาคงที่เป็นบาทของปีอ้างอิง แกนเกมปรับด้วยเงินเฟ้อจริง — ค่าเทอม · ค่ารักษา · ข้อเสนอการเงินใบ 11 · กันไม่ให้ความเหลื่อมล้ำเรื่องค่าใช้จ่ายจำเป็นหายไป (ใบ 03)
- **ผลสุ่ม**: ตัวเลือกเดียวมีผลหลายทาง น้ำหนักเปลี่ยนตามค่าสถานะ/ฐานะ/กรรม (ธุรกิจ · หวย · กรรมตามทัน)
- **บุญบาป**: ทุกตัวเลือกติดป้าย หมวด (บาป 8 หมวดพระมาลัย · ทาน/ศีล/ภาวนา · ประจำวัน) + ระดับ 1–3 ได้หลายป้าย · ตัวเลือกที่ไม่เกี่ยวต้องเขียน "กลาง" ชัด ๆ · น้ำหนักต่อหมวดอยู่ตารางกลาง (รับเรื่องจากใบ 09)
- **ป้าย ↑/↓/? บนตัวเลือก**: คำนวณจากผลอัตโนมัติ (ผลคงที่ = ↑/↓ · ผลสุ่ม = ?) · เหตุการณ์ประกาศซ่อนบางค่าได้ (เช่น ถูกหลอก) · บุญบาปไม่แสดงเลย (บัญชีซ่อน ใบ 09)
- **เชื่อมข้ามเวลา**: ตัวเลือกตั้งธง (สูบบุหรี่ · แต่งงาน · หนี้นอกระบบ) + นัดเหตุการณ์ต่อเนื่องในอีก N ปี
- **การ์ดเล่าเรื่อง**: ตัวเลือก 0 ข้อได้
- **ข้อความ**: ช่องแทนค่า {ชื่อ} {อายุ} {จังหวัด} {เงิน} {ปี} {ชื่อลูก} + คำที่อ่านจากค่า **"คำพูด" ที่แยกจากเพศกำเนิด** (ค่าตั้งต้นตามเพศกำเนิด · จะมีเหตุการณ์ให้เปลี่ยนไหมค่อยตัดสินตอนทำเนื้อหา) · ยุคต่างกันมากให้แยกเป็นเหตุการณ์คนละตัวใช้ช่วงปี

### ขั้นตอน AI ร่าง
- **ลำดับ**: ชุด 0 = หลักไมล์บังคับ + ช่วงที่ 7 (เล่นครบวงจรได้เร็ว harness รันได้ทันที) → ชุดละ ~20 เหตุการณ์ตาม ช่วงวัย × หมวด (เรียน · งาน/เงิน · ครอบครัว · สุขภาพ · ความเชื่อ · บ้านเมือง) · harness บอกช่องที่เนื้อหาบางเป็นชุดถัดไป
- **ด่านอัตโนมัติ (ไม่ผ่าน = ไม่ถึงมือเจ้าของ)**: โครงข้อมูลครบ (ฟิลด์บังคับ · ป้ายบุญบาปทุกตัวเลือก · ธงที่ขอใช้มีคนตั้ง · สินทรัพย์ไม่โผล่ก่อนปีที่มีจริง เช่น หุ้นก่อน 2518 · กยศ.) · คำต้องห้าม (การเมือง/สถาบัน · พระ/พระพุทธรูปเป็นตัวตลก · "เพราะเกิดภาค X" · ประโยคแนะนำการลงทุนจริง · ชื่อองค์กรจริงในทางทุจริต) · เหตุการณ์อิงข้อเท็จจริงต้องอ้างหัวข้อใน `lore-*.md` · ความยาวข้อความพอดีการ์ด · ด่านคำต้องห้ามจับได้ไม่ครบ เจ้าของยังต้องอ่าน
- **เจ้าของตรวจ**: หน้า HTML วาดการ์ดทั้งชุดเหมือนในเกม + ผลด่านอัตโนมัติ · กด ผ่าน/แก้/ทิ้ง + คอมเมนต์ → คัดลอกผลให้ AI แก้ไฟล์ · ตรวจน้ำเสียง · ความถูกต้องทางวัฒนธรรม · ความสนุก · ตัวเลขปล่อยให้ harness

### harness จำลอง
- **ใช้แกนเกมตัวเดียวกับเกม** (โมดูล JS ไม่แตะหน้าจอ: สุ่ม · เลือกเหตุการณ์ · คิดผล · ตาย · ฉายา) รันใน Node · ต้องวางโครงโค้ดแยกตั้งแต่ต้นแบบ
- **บอทหลายบุคลิก**: สุ่มล้วน · สายบุญ · สายบาป · สายเงิน/เสี่ยง · สายครอบครัว · สายสุขภาพ · เลือกจากป้ายที่ผู้เล่นเห็นเท่านั้น
- **รอบ**: 20,000 ชีวิต seed ตายตัว (เทียบก่อน/หลัง) + seed สุ่มอีกชุด (กันปรับจนผ่านแค่ seed เดียว) · ก่อนปล่อยรัน 100,000
- **ด่าน 4 ตัว**: (1) ฉายา/ลวดลายทุกตัว ≥0.1% รวมทุกบุคลิก (2) ไม่มีเหตุการณ์/ตัวเลือก/ธงตาย (3) อายุเฉลี่ยบอทสุ่มห่าง e0 จริงของยุค/เพศไม่เกิน ±3 ปี (4) ชีวิตที่ตายหลังอายุ 60 ≥90% ยาว 80–150 การ์ด
- **จังหวะบังคับ**: ระหว่างทาง = เหตุการณ์ในชุดใหม่ต้องไม่ตาย + ค่าอื่นไม่แย่กว่ารอบก่อน (เก็บผลรอบก่อนไว้เทียบ) · ก่อน push เวอร์ชันที่ประกาศว่าเล่นได้ครบ = ผ่านครบ 4 ด่าน
- **ตายตอนเด็ก**: คง e0 จริง (รวมการตายวัยเด็ก ตามคำตัดสินสถิติจริงใน MAP) · ตายเด็กได้การ์ดบันทึกสั้นบอกสถิติยุคนั้น แล้วเข้าช่วงที่ 7 ตามปกติ
