# MAP: สเปก + ต้นแบบเล่นได้ของเกมจำลองชีวิตคนไทยหลายรุ่น มีแฟนตาซีคติไทย

repos: ยังไม่มี (สร้างตอนเริ่มเขียนต้นแบบ) · ตั้งเมื่อ 2026-10-22

## Destination

สเปกเกมที่ตัดสินใจครบ + ต้นแบบ HTML ไฟล์เดียวที่เล่นได้ครบวงจร: เกิดในไทย → ใช้ชีวิต 15–20 นาที → ตาย → ช่วงระหว่างชาติ (ยมโลก/บุญบาป) → เล่นต่อเป็นลูกหลาน และคนอื่นหยิบไปสร้างต่อได้โดยไม่ต้องตัดสินใจเพิ่ม

## Notes

การตัดสินใจระดับจุดหมาย (grilling 2026-10-22 — ตัดสินแล้ว ไม่ต้องเปิดใบงานซ้ำ):
- ฉาก: ประเทศไทยประเทศเดียว · ใช้สถิติจริงเฉพาะจุดเกิด (จังหวัด · ฐานะ) และอายุคาดเฉลี่ย ส่วนเหตุการณ์ประมาณเอาได้
- ขยาย 2026-10-22 (ระหว่างทำใบ "โครงชีวิต"): **สุ่มปีเกิด 2500–2569 ถ่วงตามจำนวนเกิดจริง** · เงินเฟ้อจริง · ปีเลยปัจจุบันสุ่มจากสถิติย้อนหลัง + ไซไฟเบา ๆ · เหตุการณ์จริงเฉพาะเศรษฐกิจ/ภัยพิบัติ ไม่แตะการเมือง
- จังหวะ: กดต่อเอง เล่นละเอียด 15–20 นาทีต่อชีวิต (ต้องมีเหตุการณ์ราว 80–150 เหตุการณ์)
- ค่าสถานะ: สุขภาพ · ความสุข · ความรู้ · ความสัมพันธ์ + เงิน/หนี้ · ผลของตัวเลือกบอกแค่ทิศทาง (↑/↓) ไม่บอกตัวเลข
- เพิ่ม 2026-10-22 (user ขอหลังตั้ง map — กลับคำตัดสินเดิมที่ไม่เอาบุญบาป): ระบบ **บุญบาป** · **การเงินการลงทุน** · **ความเชื่อ (สายมู)** เป็นระบบหลัก รายละเอียดอยู่ในใบงานของแต่ละระบบ · ในเกมห้ามมีข้อความที่อ่านเหมือนคำแนะนำการลงทุนจริง
- แก่นเกม: เล่าเรื่องเป็นหลัก + ฉายาเสริม 2 ชั้น (ลวดลายจากแกนคู่แบบ 1in8b + ฉายาตามเงื่อนไขแบบ 65 ล้าน)
- หลังตาย: เล่นต่อเป็นลูก หลายรุ่นเต็มระบบ (ต้นแบบต้องครอบด้วย)
- แฟนตาซี: คติไทย (ผี · เทวดา · พญายม · นาค · เจ้าที่ · กรรม) อยู่ทั้งช่วงระหว่างชาติและแทรกเบา ๆ ในชีวิต · มีผลกับกลไกจริงแต่จำกัด ห้ามทำให้สถิติจริงเสียความหมาย
- เทคนิค: HTML ไฟล์เดียว ไม่มี backend · เซฟใน localStorage · สไตล์การ์ดตัวหนังสือ + ภาพพิกเซลเล็ก
- เนื้อหา: AI ร่าง แล้วเจ้าของคัดและแก้
- บทเรียนจากการแกะ 2 เกม (ใช้เป็นหลักฐาน): เงื่อนไขฉายาที่เรียงลำดับทำให้ฉายาบางตัวไม่มีทางได้ ("ชีวิตที่หนักหนา" ใน 65 ล้าน 0/80,000 ชีวิต) · การบอกผลเป็นตัวเลขทำให้สคริปต์เล่นแทนได้ง่าย · ควรมี harness จำลองชีวิตแบบตั้ง seed ได้ไว้ใช้ปรับสมดุลตั้งแต่วันแรก (ทั้ง 2 เกมมี และเราใช้วัดผลตัวเลือกได้)
- skill ที่ใช้: `grilling` + `domain-modeling` สำหรับใบ grilling · `research` brief ตรงสำหรับใบ research
