คำตอบที่ตัดสิน

  1. ปิดใบ 04/05: ปิด 05 เปิด 04 ต่อ
  2. ใบ 05 เพดานอายุไทยจากอีเวนต์ชวนไปต่างโลก: ปิด 05 + ด่านใหม่ — บอทกดรับการ์ดชวน อายุไทยเฉลี่ยลดไม่เกิน N ปี · เป็นใบงานเลน B
  3. ใบ 02 อายุตายต่างโลก: วัดของตอนนี้แล้วล็อก ±3 ปี → หลังผู้ค้าน: ขยายด่าน 65–95 เดิมทุกเผ่า (คูณ pace · ไม่ต้องมีค่าฐานแช่)
  4. ใบ 03 ทายาทต่างโลก: 1+ลูกศิษย์ → 3 ใบปนกัน สายเลือด+ศิษย์ → หลังผู้ค้าน: เปิดใบระบบครอบครัวต่างโลกก่อน
  5. ศิษย์มาจาก: การ์ดรับศิษย์ระหว่างชีวิต → หลังผู้ค้าน: การ์ดตามอาชีพ/ชื่อเสียง เพดาน 1–3
  6. ช่องทายาทไม่ครบ: เติมด้วยแฟ้มแคว้น/เผ่า → หลังผู้ค้าน: แยก 2 ปุ่ม (ทายาท/ศิษย์ ≤3 ใบ | แฟ้มคนแปลกหน้า 3 ใบ)
  7. ใบ 03 โลกจำเหตุการณ์ใหญ่: เพิ่มสภาพโลกจากเหตุการณ์ใหญ่ · สภาพต่อแคว้น
  8. เก็บ/แสดงสภาพแคว้น: เก็บบนผังตระกูล + แฟ้มเกิด 1 ใบเป็นแคว้นที่เปลี่ยน
  9. สภาพแคว้นมาจาก: ฉากจบชาติ → หลังผู้ค้าน: ต่อยอดตำนาน (ดังถึงเกณฑ์ = แคว้นของชาตินั้นติดสภาพ "ยังเล่าถึง/ยังกลัว")
  10. สภาพแคว้นอยู่นานแค่ไหน: ถาวรจนถูกเปลี่ยน → หลังผู้ค้าน: สภาพชนะผลสุ่ม + ล้างตอนจบโลก
  11. ใบ 04 สู้ปกป้อง: แยก ไม่ฆ่า=บุญ ฆ่า=กลาง → หลังผู้ค้าน: ฆ่าเพื่อปกป้อง = ช่วยคน ระดับ 1
  12. ใบ 04 ทรยศ: ใช้ vow_broken ที่มี → หลังผู้ค้าน: เพิ่มหมวดทรยศใหม่
  13. ใบ 04 รักษาสัญญา: คงเฉพาะเทพธิดา
  14. ใบ 04 ฝืนธรรมชาติ · สัญญามาร: รับทั้งสอง

คำตอบที่ตัดสิน

  1. ขอบเขต: ครบเหมือนชาติไทย → (หลังผู้ค้าน) ใช้ family.mjs ร่วม + ตัวแปลงต่างโลก · ส่งทีละชิ้น คู่+ลูกก่อน
  2. แต่งงาน/มีลูกเกิดยังไง: การ์ดในกองต่างโลก ผู้เล่นเลือก
  3. ชีวิตแบบไหนมีครอบครัวได้: ทั้งสอง มีลูกได้ (ชาติเต็ม + ทริป)
  4. คู่ชีวิตมาจากใคร: 1+2+3 ต่างโลกตัดสามัญสำนึกโลกหลักได้ → (หลังผู้ค้าน) การ์ดสร้างคู่ใหม่เอง ไม่ดึงคนเก่า
  5. ทริปมีลูกแล้วกลับไทย: อยู่ต่างโลก เป็นทายาทในโลกนั้น → (หลังผู้ค้าน) เก็บลูกในแถวทริป ลูกโตตามเวลาที่ผ่านไปในโลกนั้น
  6. ลูกครึ่งเผ่า: เผ่าครึ่งใหม่ (ฮาล์ฟเอลฟ์ ฯลฯ)
  7. ต่างโลกทำได้แต่ไทยไม่มี: คู่หลายคน (ฮาเร็ม), คู่เป็นสัตว์อสูร/ปีศาจ/เทพ, อายุห่างมากได้, ลูกโตเร็ว/เกิดด้วยเวท → (หลังผู้ค้าน) ผู้เล่นและคู่อายุ 20 ขึ้นไป, สัตว์อสูรเป็นคู่หู ไม่ใช่คู่ชีวิต, อายุห่างมากได้เฉพาะผู้ใหญ่ทั้งคู่
  8. ทำยังไง: เขียนชุดต่างโลกแยก → (หลังผู้ค้าน) ยุบเข้าข้อ 1 (ใช้ family.mjs ร่วม)
  9. เผ่าครึ่ง: ครบ 28 คู่ → (หลังผู้ค้าน) ตารางแยก ไม่ปน 8 เผ่าเกิด + ด่านอายุวัดรวมกลุ่มเดียว
  10. คู่พิเศษมีลูก: 1+2 (เผ่าพ่อแม่ฝั่ง 8 เผ่า + ธงเลือดพิเศษ · เผ่ากึ่งใหม่)
  11. ค่าเผ่าครึ่ง: สูตรเฉลี่ยพ่อแม่ + ชื่อเขียนเอง
  12. ข้อ 10 ออกแบบไหน: ตามชนิดคู่ → (หลังผู้ค้าน) เผ่า demon = 28 คู่ · จอมมารเป็นชนิดคู่แยก มีป้ายชัด
  13. ฮาเร็ม: ไม่จำกัด · ไม่ติดบาป → (หลังผู้ค้าน) หลายคู่ได้ คู่เดิมต้องยอม ไม่ยอม = บาปหมวดทรยศ + แก้ SPEC
  14. คุมความถี่: อยู่ในโควตาการ์ดครอบครัวเดิม → (หลังผู้ค้าน) 1+2 = เรื่องทุ่มเท "สร้างครอบครัว" + จำนวนคู่ = จำนวนการ์ดคู่ และตั้งเพดานคู่ต่อชาติเป็นตัวเลข
  15. ลูกเวทมาจาก: 1+2+3 → (หลังผู้ค้าน) การ์ดหายาก + คู่พิเศษเท่านั้น ใช้ค่าเวทเป็นเกณฑ์
  16. คัดทายาท: เปิดรายชื่อให้เลือกทุกคน → (หลังผู้ค้าน) รายชื่อเต็ม เลื่อนดูได้
  17. เพดานคู่ต่อชาติ (ค้างจากข้อ 14): มีโอกาสได้เพิ่มเรื่อยๆ (ไม่ตั้งเพดานตัวเลข · ทับครึ่งหลังของข้อ 14 · คู่เดิมยังต้องยอมตามข้อ 13)
